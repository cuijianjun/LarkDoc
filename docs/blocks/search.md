# 查找替换

查找替换组件提供全文检索、命中计数、上一个 / 下一个导航与逐个 / 全部替换。命中项以高亮装饰渲染；命中被折叠块内的内容时自动展开它。

## 配置示例

```ts
new LarkDoc({
  element: '#editor',
  features: { search: true },
  toolbarKeys: ['search'],       // 查找替换入口（别名 find）
})
```

## 配置与用法

| 配置项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `features.search` | `boolean` | `true` | 关闭后查找替换面板隐藏。 |
| `commands.disabled: ['openSearch']` | `string[]` | `[]` | 禁用打开命令。 |

### 使用方式

| 入口 | 操作 |
| --- | --- |
| 工具栏 / 快捷键 | 打开查找面板（`Mod+F` 语义）。 |
| 输入框 | 实时检索，显示「第 n / m 处」。 |
| 上 / 下箭头 | 在命中项间循环导航。 |
| 替换 | 逐个替换或全部替换，替换结果并入撤销历史。 |

### 行为细节

- 命中折叠内容：自动执行 `revealLarkDocMatch` 展开所在章节后再定位。
- 大小写：默认区分大小写；空查询不触发检索。
- 只读模式：查找可用，替换按钮禁用。
