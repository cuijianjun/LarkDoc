# 功能文档

这里按“你想使用什么能力”组织 LarkDoc 的功能说明。

不需要先了解项目目录，直接从下面选择功能即可。

## 快速找到功能

| 你想做什么 | 从这里开始 |
| --- | --- |
| 编辑文字、标题和列表 | [基础编辑](#基础编辑) |
| 插入表格、图片和公式 | [内容块](#内容块) |
| 折叠、查看目录或查找文字 | [文档操作](#文档操作) |
| 配置工具栏和编辑器入口 | [编辑器交互](#编辑器交互) |
| 使用 AI、上传或网络策略 | [智能与扩展](#智能与扩展) |
| 使用多人协同和权限 | [协同与权限](/guide/collaboration) |

## 基础编辑

| 功能 | 说明 |
| --- | --- |
| [标题](/blocks/heading) | 使用标题组织文档结构。 |
| [段落](/blocks/paragraph) | 编辑普通段落和段落样式。 |
| [文字格式](/blocks/marks) | 设置加粗、斜体、下划线等格式。 |
| [文字样式](/blocks/text-style) | 设置文字颜色、背景和行内样式。 |
| [列表](/blocks/lists) | 使用有序、无序和任务列表。 |
| [引用](/blocks/quote) | 使用引用块突出显示内容。 |
| [链接](/blocks/link) | 添加和编辑链接。 |
| [表情](/blocks/emoji) | 在文档中插入表情。 |

## 内容块

| 功能 | 说明 |
| --- | --- |
| [代码块](/blocks/code-block) | 展示代码并进行语法高亮。 |
| [高亮块](/blocks/callout) | 用提示、警告等样式强调内容。 |
| [分栏](/blocks/columns) | 将内容排布到多个栏目中。 |
| [表格](/blocks/table) | 创建和编辑表格。 |
| [图片](/blocks/image) | 插入和管理图片。 |
| [数学公式](/blocks/math) | 在文档中编写数学公式。 |
| [导入导出](/blocks/import-export) | 处理文档内容的导入和导出。 |

## 文档操作

| 功能 | 说明 |
| --- | --- |
| [折叠块](/blocks/folding) | 折叠或展开一段内容。 |
| [目录](/blocks/outline) | 根据标题浏览和定位文档。 |
| [查找替换](/blocks/search) | 在文档中查找或替换文字。 |
| [块句柄与拖拽](/blocks/block-handle) | 移动、复制或操作文档块。 |
| [视图模式](/blocks/view-modes) | 切换文档的显示方式。 |
| [模板](/blocks/templates) | 使用预设内容快速创建文档。 |
