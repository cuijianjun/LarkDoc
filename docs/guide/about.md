## 背景

### 为什么写

用于个人学习与技术研究的练习项目，目的是吃透富文本编辑器的工程实现：

- ProseMirror 的文档模型与事务（transaction）机制
- Tiptap 3 的扩展（Extension / Node / Mark）、命令与插件体系
- Vue 2.7 渲染层与编辑器状态的边界（`EditorContent`、装饰 widget、浮层定位）
- 具体问题：块级结构、折叠与高亮、标题自动编号、列表缩进与序号、气泡菜单、表格交互、导入导出归一化

仓库里的大量代码注释，以及 [`dev/` 开发手册](https://github.com/cuijianjun/LarkDoc/tree/master/dev) 中的踩坑清单，
本质上是学习笔记，不是产品交付物。

### 为什么长这样

把「飞书文档」作为还原目标，是为了有一个明确、可对照的高标准参照物 —— 行距、字号、菜单层级、
图标位置这类细节都去真飞书里实测过（见 DEVELOPMENT.md 的「排版实测值」）。

这是**模仿练习**（类似临摹字帖），不是复刻其实现：

- 所有代码、样式、图标均为本仓库自写
- 未使用飞书的任何代码、接口、设计源文件、商标或 Logo
- 未接入飞书开放平台或任何其内部服务

### 为什么开源

方便自己回溯，也方便与他人交流编辑器实现细节；顺带给同样在研究 Tiptap / Vue 2 编辑器的人一个可跑的样本。
