# 插入弹窗交互统一改造说明

> 来源说明：本文记录 demo 原生 DOM 工作树的改造背景。dev 仍使用 Vue2 渲染，本次合并将菜单交互移植到 `CommandMenu.vue`、`editor/ToolbarBar.vue`、`editor/BlockHandleMenu.vue` 和 `editor/icons.js`；下列 `src/ui/*` 路径是源架构记录，不代表 dev 已具备这些模块。文末校验属于源工作树历史记录，本次仅做轻量静态核验，未执行构建或浏览器验收。

## 改造范围

本次统一覆盖：

- 工具栏「插入」按钮
- 空段落左侧「＋」按钮
- 编辑器中输入 `/` 后出现的斜杠菜单
- 工具栏「图表」按钮及图表类型菜单（六种图表使用不同的彩色语义图标）
- 加号/斜杠菜单中的模板、分栏、表格等右侧子菜单

## 交互原则

所有入口优先复用现有原生 renderer 和浮层关闭机制：

- 加号与斜杠共用 `src/ui/commandMenu.js`。
- 子菜单继续使用同一套真实尺寸定位、视口边界夹取和左右翻转逻辑。
- 图表类型继续使用 `diagramTypes` 与 `insertDiagramType()`，不复制插入事务。
- 浮层统一支持悬停保持、约 150ms 延迟关闭、点击切换和 Escape 关闭。
- 菜单触发器补充 `aria-haspopup="menu"` 与 `aria-expanded`，菜单保留 `role="menu"` / `role="menuitem"`。

## 入口行为

### 加号与空段落「＋」

移入工具栏「插入」或空段落「＋」时，保留当前选区并打开同一个加号菜单。鼠标移入菜单或右侧子菜单时取消关闭计时器；离开后延迟关闭，避免跨越按钮与菜单之间的间距时闪退。点击仍然可以打开/切换，键盘导航和搜索行为不变。

### 斜杠菜单

斜杠菜单仍由编辑器插件根据 `/query` 驱动，不改动其删除触发文本、IME 组字和 Escape dismissed 逻辑。它和加号菜单共用 DOM、搜索、键盘和子菜单 renderer。

### 图表菜单

图表按钮支持 hover 和 click 两种入口。移入打开六种已有 Mermaid 类型；移入菜单保持打开；移出后延迟关闭。菜单空间不足时自动向上翻转，并根据真实高度限制最大高度。选择类型后统一调用 `insertDiagramType(typeId)`。
