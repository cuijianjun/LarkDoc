# 6. 打包与体积

> 所属：lark-doc 开发备忘分册　|　返回导航：[`dev/00-INDEX.md`](./00-INDEX.md)

库使用 Rollup，应用保留原有工具链。构建配置以 `rollup.config.mjs`、`scripts/build-rollup.mjs` 为准；使用方入口与部署说明见[打包产物](../docs/guide/build-artifacts.md)。旧 Webpack 的 LimitChunkCountPlugin、output.library、build-esm.js、publicPath 与 --no-clean 规则不再用于当前库构建。

## 6.1 构建与副作用

| 约束 | 当前做法 |
| --- | --- |
| 入口、特性与样式 | 默认 / full / lite 显式引公共 CSS；Element ESM/UMD 注入样式。features 通过模块副作用注册实现。 |
| sideEffects | package.json 已有明确白名单，保留 CSS、特性注册与必要入口。修改前检查真实打包器树摇结果，不能笼统禁止该字段，也不能直接改成 false。 |
| 模块与拆包 | 默认/full/Vue2 options 提供 ESM、CJS；lite 与 ESM features 支持按需实现；Element 有现代 ESM 与浏览器直挂 UMD。CJS 通过相对 require 加载兄弟 chunk，不是单文件。 |
| Mermaid | ESM 入口共用同格式共享运行时，CJS 使用自己的共享文件；默认按需、full 静态注册、lite 不携带实现。CDN 特性 UMD 使用同目录 sidecar。 |
| Webpack4 兼容 | 根 ESM 和可达 chunk 已降语法，宿主无需 SDK alias。Element ESM 的 import.meta.url 用于现代打包器；老宿主标签方案独立 script 加载 UMD。 |
| 框架与协同 | 库产物无 Vue 或 Webpack runtime；Vue2 options 由应用已有 Vue2 执行。协同依赖从显式 collab 子入口 external，保持同格式 ProseMirror/Yjs 单例。 |
| 产物清理 | build-rollup 按目标和记录的输出维护构建图；完整 all 构建才按所有目标的归属清理已知旧 chunk。不要手工删除其它目标产物或套用旧 --no-clean 命令。 |

```bash
npm run build          # 默认 ESM + CJS
npm run build:full
npm run build:lite
npm run build:features
npm run build:element
npm run build:vue2
npm run build:all       # 发布所需全部目标
npm run check:rollup
npm run check:lite
npm run check:legacy
npm run size
```

运行时与安装要求见[环境与校验链](./01-环境与校验链.md)。构建耗时必须分开记录冷构建、复用构建、应用冷构建与缓存构建；更换库构建器不能直接证明应用变快。

## 6.2 体积测量口径

`npm run size` 实际执行 `scripts/check-rollup-artifacts.mjs --size`，读取 Rollup 生成的 `dist/lark-doc-graph.json`，由 `scripts/artifact-graph.js` 遍历静态与动态边。预算值仍放在 package.json 的 size-limit 字段；不是用一个转发入口文件的 gzip 代表整个编辑器，也不是旧 Webpack 单文件预算。

| 当前预算对象 | gzip 上限（十进制 KB） |
| --- | --- |
| 默认 ESM 的 editor 代码 | 310 KB |
| Element UMD 初始图 | 475 KB |
| CJS 初始图，含真实外部 PM require 闭包 | 1080 KB |
| collab ESM 初始图 | 4 KB |
| lite 的 editor 代码 | 300 KB |

ESM / lite 的 editor 预算排除被构建图标记为 runtime 的部分，但输出必须同时报告**全部静态初始图**与**包含动态区块的完整图**。Tiptap、core-js、静态 ESM 的 PM 模块和 CJS 的外部 PM 不能在说明中消失。当前数值以命令输出为准；预算变化必须说明原因，不能通过抬高阈值掩盖回归。

改构建后至少检查公开 exports、语法、离线资源、lite 排除重实现和真实消费；需要图表的环境还要在浏览器确认 SVG。历史 Webpack 体积和旧优化结论仅供对照，不能作为当前产物结构的限制。
