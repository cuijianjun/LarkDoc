# 多环境接入约束

返回 [开发导航](./00-INDEX.md)。应用可复制示例统一维护在 [各环境接入](../docs/guide/environments.md)。

## 入口与样式

| 入口 | 使用场景 | 样式 |
| --- | --- | --- |
| `lark-doc` | 默认按功能懒加载，所有框架可命令式挂载 | 引 `lark-doc/style.css` |
| `lark-doc/full` | 显式全量功能 | 引 `lark-doc/style.css` |
| `lark-doc/lite` + `lark-doc/features/*` | 按需注册功能 | 主样式；math 按指南另引功能样式 |
| `lark-doc/vue2` | Vue2 组件适配器，使用宿主 Vue | 引主样式 |
| `lark-doc/vue3`、`lark-doc/react` | 需先加载 `lark-doc/element` 的标签适配器 | 由 Element 提供样式 |
| `lark-doc/element` | Web Component | 自带样式，无需重复引 CSS |
| `dist/lark-doc-element.umd.min.js` | CDN / 静态 HTML | 自带样式，同目录提供功能脚本与字体 |

库的构建和运行时不依赖 Vue / Webpack。Vue2 适配器是纯组件 options，Vue 由应用提供。
默认、全量、lite、适配器、Element ESM/UMD、CJS 都由 Rollup 构建；应用不更换 Vite / VueCLI / Webpack。
不要恢复旧 SFC 根导出、内联 Vue 或旧 Webpack runtime 后处理。

## 打包器与部署

Webpack4 按 `main/module` 选择真实根入口已验证，无需根 alias；CSS 子入口写物理路径
`lark-doc/dist/lark-doc.css`。其它不识别 `exports` 的子入口同样使用公开物理路径，
见使用方指南。不要通过删副作用声明、忽略 Babel 所有依赖或换应用工具链来提速。

ESM 与 CJS 包含多个真实 chunk；部署/分发保留整个 `dist/`，不能只取入口壳。
ESM 的本地 PM 图确保同一编辑器使用相同 ProseMirror 身份；不要随意替换内部导入路径。
Element UMD 用主脚本 URL 定位五个功能脚本，必须同目录部署，字体保留 `fonts/`。
同格式 Mermaid 运行时共享；检验真实可达图与 SVG，不只看入口文件大小。

## 上传配置跨环境一致

所有环境使用相同的 `uploader` 对象：自定义 `upload` 优先，其次内置 `action`，都没有时本地 base64。
服务器返回数据通过 `response` 映射；失败不会自动转为 base64。
Vue2 用 `:uploader`；命令式构造放 `options.uploader`；Web Component 必须传 `.options` 对象属性，
不能用 HTML 字符串属性传函数。Vue3 / React 适配器保留函数身份。

选文件、粘贴、拖拽、替换、裁剪共用上传管线并通知应用完整生命周期。
已有图片 URL 直接插入不会伪造文件上传回调；上传成功、正文插入、应用保存是三个不同阶段。
完整参数和回调以 [上传器文档](../docs/blocks/uploader.md) 为准。
配置更新使用现有 `setUploader` 或框架对应属性更新，不重建编辑器，以保留正文、标题和撤销历史。

## 验证边界

Node / SSR 端只做安全导入，不在服务端执行 DOM 挂载或图表布局。
框架组件在 mounted / effect 后初始化，在卸载时 destroy；React StrictMode 应允许挂载、卸载、再次挂载。
应用侧使用同一个真实 npm tarball 普通安装，检查实体文件与完整性后构建、再验证浏览器。
三个框架、各适配器、原生入口、CDN 与 Webpack4 的已运行证据见 [性能与环境结果](../docs/guide/performance.md)。
