## 5. 验证资产

### 5.1 统一入口（2026-10-27 起）

```bash
npm run verify:list                        # 列 11 个可用目标
npm run verify -- highlight-fold list-marker   # 一条命令顺序跑多个
npm run verify:all                         # 全跑（约 11 次浏览器启动，慎用）
```

- **输出只有 PASS/FAIL 一行**：成功打 `PASS <目标> <耗时>` + 一行统计；失败打 `验证脚本异常: <一行>` + 日志路径。
  原始输出**永远写文件** `_codex/verify-logs/<目标>.log`（已被 gitignore），要细节去读文件，不要把 stdout 灌进上下文。
- 汇总另存 `_codex/verify-logs/latest.json`（每个目标的 code / ms / 日志路径），给下一个会话或 CI 一行取值。
- 前置：dev server 在 8080 跑着（脚本只探活警告，不负责拉起）；Node ≥ 18，`NODE_PATH` 未设时自动补本机 playwright-core 路径。
- 超时默认 240s，可 `npm run verify -- theme --timeout=60`。

### 5.2 断言清单

| 脚本 | 项数 | 覆盖 |
|---|---|---|
| `scripts/check-lark-doc-core.js`（随 `npm run check`） | — | 折叠子树 / 编号 / 缩进 / 命令等核心断言 |
| `scripts/check-vditor-html.js`（`check:vditor`） | 93 | Vditor HTML 导入 |
| `verify highlight-fold` | 74 | 悬停高亮 + 折叠（含几何） |
| `verify heading-number` | 38 | 标题编号菜单 / 交互 |
| `verify heading-menu` | 16 | 标题级别下拉（工具栏 ⇄ 气泡条）必须同款 |
| `verify list-marker` | 23 | 列表标记 |
| `verify list-number-menu` | 30 | 列表序号可点 + 浮层无滚动条 + 跨列表接号 |
| `verify icon-align` | 7 | 图标 / 控件与首行文字的垂直居中（任务框、callout emoji、列表标记、气泡条按钮） |
| `verify mermaid` | 18 | 图表渲染（懒 chunk 寻址 + 真实 SVG + **全页零外链**） |
| `verify element` | 14 | WC / element 场景 |
| `verify colors` / `verify theme` | — | 主题色板与明暗模式 |
| `verify splitting` | 手动 | 按需区块下载（首屏不漏 office/markdown/highlight、element chunk 寻址、mermaid 懒 chunk、highlight 按需）；**需 demo 在跑**，未进 `check` 链 |

- 新增 UI 行为**顺手加断言**，不要只靠截图；截图只用于视觉核对。
- **断言懒 chunk 只能监听 `request` / `response` 事件**：webpack JSONP 加载完会移除 `<script>`，`networkidle` 之后回 DOM 查 `script[src*=mermaid]` 一定是空（这条踩过，`verify-browser-splitting.js` 已按新契约改）。
- mermaid 断言分两层：jsdom（`check-vditor-html.js`）只能断言错误态 UX 与「无 script 注入 + bundle 内含 mermaid 标记（`flowchart-v2`，该串只在 mermaid.min.js 里出现）」，真实渲染与零外链归 `verify-browser-mermaid.js`；WC 预构建产物路径（`/lark-doc-wc`）用一次性 playwright 脚本验懒区块相对寻址，未留正式文件。
- **文档站是独立子包**：`docs/` 自带 `package.json`（`vitepress ^1.6.3` + 自己的 `node_modules`），所以不占本包的 Node 14 依赖。改完 md 必须跑 `cd docs && npm run docs:build`（VitePress 对**死链**是 hard error，这是文档站唯一的校验手段）；内网出包见 `scripts/pack-docs.sh` 与 [`docs/guide/deployment-docs-site.md`](../docs/guide/deployment-docs-site.md)。
