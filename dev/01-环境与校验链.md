# 环境与校验链

返回 [开发导航](./00-INDEX.md)。初次运行见 [本地开发与验证](../docs/guide/development.md)。

## 运行时

| 用途 | Node / npm |
| --- | --- |
| 库兼容构建与产物检查 | Node 14.21.3 / npm 8.19.4 |
| 完整单测与门禁 | Node 22.12+ 或 Node 24；发布脚本使用 Node 24.22.0 |
| 文档站 VitePress | 独立 `docs/` 子包，CI 使用 Node 20 |

`.nvmrc` 指向库的 Node 14；Vitest 5 不能在 Node 14 运行。应用侧继续使用自己的版本和锁文件。
宿主注入 `NODE_OPTIONS` 时，按下方命令清除后再检查。

## 按改动选择命令

在仓库根目录运行：

| 改动 | 验证命令 |
| --- | --- |
| 小范围源码 | 现代 Node：`npx --no-install vitest run test/unit/对应文件.test.js`，再 `npm run check:quick` |
| 样式与主题 | `npm run check:ui` 与 `npm run lint` |
| 导出、构建或发布 | 现代 Node：`env -u NODE_OPTIONS npm run check:gate`；Node 14：`env -u NODE_OPTIONS npm run check:artifacts` |
| 文档与 demo | 构建库 → `node scripts/demo-sync-vendor.mjs` → `node scripts/demo-sync-vendor.mjs --check` → `cd docs && npm run docs:build`，再浏览器验证 |

`npm run test:unit -- 文件名` 的脚本已经带 `test/unit`，可能仍选择全部单测。
只测指定文件时使用表中的 `vitest run` 命令。不要用未安装的最新 CLI 代替项目版本。

`check:gate` 包含部署契约、源码检查、单测、主题检查及 lint；
`check:artifacts` 校验所有 Rollup 入口、旧语法兼容、Vditor、导出图和体积。
发布前两段都必须成功。2026-11-05 本地全门禁为 92 文件 / 1972 测试通过；
其中旧 DOM 快照测试因未解析到可选浏览器依赖而内部跳过，真实浏览器环境验证另行执行。
保留第三方已有弃用和体积提示，不把它们描述为零警告。

## 构建缓存

`npm run artifacts:check` 只检查、不构建。版本、源码、依赖、构建配置、Node 主版本或 npm 调用环境变化，
以及产物内容被修改，都会使缓存失效。指纹按文件内容计算；不是只看时间或文件大小。
`npm run check:artifacts` 会在需要时统一调用 `build:all`，完整校验成功后才更新记录。
改 README、普通文档或 demo 界面不会重建库。

单测启用 `isolate: true`，避免一个测试注册的功能加载器污染其它测试。
涉及块契约时运行 `npm run contract` 与 `npm run contract:check`；缺少本地生成索引时以检查输出为准。
浏览器回归入口见 [验证资产](./05-验证资产.md)，不以 jsdom 通过代替实际图表和图片渲染。
