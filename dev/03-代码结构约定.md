# 3. 代码结构约定

> 所属：lark-doc 开发备忘分册　|　返回导航：[`dev/00-INDEX.md`](./00-INDEX.md)

## 3. 代码结构约定

- 默认入口使用原生 DOM renderer。文档能力放 `src/core/`，状态与交互由 `src/editor/`、`src/workspace/` 管理，UI 工厂放 `src/ui/`；不得重新引入 Vue SFC 或框架运行时依赖。
- 图标复用 `src/ui/icon.js` 的注册表与工厂；新增图标先注册，再由 UI 引用，避免未定义图标静默显示为空。
- 复用 `src/ui/dom.js`、`src/ui/panels.js` 等原语。共享 host 中的组件只操作自己的子树，不能整体对齐容器而删除兄弟组件；增量更新保留焦点、选区和悬停链，透传原事件以保留 `currentTarget`，条件段的 DOM/role/aria 语义保持一致。
- 下拉统一使用 `src/ui/select.js` 原生原语；不要新增 Vue 下拉组件。
- 协同 / 权限走门面：`new LarkDoc({ session | providers/documentId/user/mode/capabilities })`，`doc.getSession()/can()/connectCollaboration()`，架构测试 `check-architecture.js` 守卫。
