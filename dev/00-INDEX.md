# lark-doc 开发备忘 · 总导航

> 这份备忘原来是一篇 41 KB 的 `DEVELOPMENT.md`，被标成「改代码前必读」——每开一个会话先交 9k token 税。
> 现在按域拆开：**先查表定位，再只读命中那一册**（通常 1–2 KB）。

## 三条读法

1. **不要整篇读**。下面每个链接都是独立文件，`Read` 单个文件即可，不要用 `offset/limit` 去翻兄弟册。
2. **改块类型先看契约索引**：`_codex/contract/INDEX.md`（约 950 token，一屏列出 42 个文件 / 28 个真块的 attrs / 关键常量 / 证据锚点 / 源码位置）。
   契约由 `src/core/blocks/*.js` 生成，**代码是真源**，所以不会和实现漂移。改完代码跑 `npm run contract` 更新，`npm run contract:check` 判过期。
   生成器怎么工作、有哪些局限：[`08`](./08-工具与生成物.md)。
3. **要飞书实证证据才回查 `requirements/`**。契约里的「证据」列给了 `02 §N` 锚点，按锚点读那一节，不要裸读整个 `02-块类型规格总表.md`（10 万 token）。
