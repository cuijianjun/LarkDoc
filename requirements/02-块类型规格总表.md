## 0. 所有块共用的通用能力（先读这一节）

飞书里「块（block）」是第一公民。下面这些能力**每一类块都必须具备**，复刻时应做成通用层而不是逐块实现。

### 0.1 通用 CRUD 闭环

| 操作 | 入口（全部都要有） | 边界条件 |
| --- | --- | --- |
| **增** | ① 斜杠菜单 `/`；② 空行回车（文本块）；③ 块手柄「+」按钮（部分块）；④ 粘贴/拖拽导入；⑤ Markdown 输入规则（`# `、`- `、`1. `、`` ``` ``、`> `） | 块内空内容回车 → 退出块变文本块（除代码块/表格） |
| **改** | ① 直接编辑内容；② 块菜单「转换为」；③ 气泡条行内格式；④ 属性面板（缩进/对齐/颜色）；⑤ 拖拽调整顺序 | 容器块（高亮/引用/分栏/表格）内部可再嵌块 |
| **删** | ① 空块 `Backspace`；② 选中多块 `Delete`/`Backspace`；③ 块菜单「删除」；④ 全选 `Cmd+A` 删除 | 删除后焦点落到**前一个可见块**末尾；文档至少保留一个空段落 |
| **查** | ① 目录（仅标题）；② `Ctrl+F` 查找；③ 折叠集合持久化；④ 评论锚点回跳；⑤ 版本历史快照 | 见 [05-接口文档](./05-接口文档.md) |

### 0.2 通用显隐规则

| 元素 | 显示条件 | 隐藏条件 |
| --- | --- | --- |
| 块拖拽手柄（六点） | 鼠标 hover 在该块区域 | 鼠标离开；只读模式隐藏 |
| 块 hover 底色 | hover | 离开；块处于编辑态（focused）时**不叠加** hover 底 |
| 空块占位文案 | 块为空 **且** 是文档最后一个块（飞书只在末尾块显示占位） | 输入任意字符 |
| 光标块 `focused` | 光标在该块内 | 光标离开 |
| 折叠箭头 | hover 在**可折叠块**（标题、列表项、文本块）上 | 不可折叠块（表格、代码块、高亮块）不显示 |
| 选区气泡条 | 有非空文本选区 | 选区为空 / 只读 / 光标态 |

### 0.3 通用属性（对所有 `paragraph`/`heading` 生效）【源码】

| 属性 | 类型 | 默认 | 落库形态 | 说明 |
| --- | --- | --- | --- | --- |
| `blockId` | `string \| null` | 自动生成 | `data-block-id` | 折叠集合 / 评论锚点的稳定引用。格式 `/^[A-Za-z0-9_-]{1,64}$/`，生成规则 `b` + base36 随机 + 自增序号 |
| `indent` | `number` | `0` | `data-indent` + `style="margin-left:Npx"` | **步长 25px，上限 5 级（125px）**。用 `margin-left` 而非 `padding`（padding 只推文字，块的 hover 高亮与手柄位置会与飞书不一致） |
| `lineHeight` | `string \| null` | `null` | `style="line-height:..."` | 取值正则 `^(normal|[1-4](\.\d{1,2})?)$` |

**带 `blockId` 的节点类型（`BLOCK_ID_TYPES`）【源码】**：
`paragraph`、`heading`、`blockquote`、`callout`、`columns`、`details`、`detailsSummary`、`listItem`、`taskItem`、`bulletList`、`orderedList`、`taskList`、`codeBlock`、`image`、`horizontalRule`、`blockMath`、`table`

> 结构性容器（`tableRow`/`tableCell`/`column`）**不编号**，父块已有 id。

### 0.4 缩进规则（飞书口径，务必照做）【源码】

| 规则 | 说明 |
| --- | --- |
| 增加上限 | = **前一个兄弟块的 indent + 1**；硬顶 `MAX_BLOCK_INDENT = 5` |
| 第一个块 | 没有前兄弟 → **一级都缩不了** |
| 减少 | 只受 0 下限限制，可一路减回文档开头 |
| 统一入口 | 所有入口（快捷键 / 工具栏 / 气泡菜单 / 块菜单 / 导入 JSON）必须走 `clampBlockIndent` + `stepBlockIndent`，**禁止任何入口自己 clamp**（历史上出现过「某入口能一直加」的 bug） |
| 归一化 | 导入的旧 JSON 缩进超限 → 事务里一次性压回上限，且 `addToHistory: false`（不进撤销栈） |

### 0.5 列表缩进（易错）【源码 + 实测】

- **顶层 `ol` / `ul` / `taskList`：`padding: 0`** —— 序号顶格对齐正文行首（飞书口径，不要给 24px）
- **只有嵌套列表**才 `padding-left: 24px` 逐层缩进
- 序号是 `li > p` 内的装饰 widget，跟着 padding 一起移动
- 列表项转标题时，定位 `listItem` **不能用 `$start.depth - 1`**（块边界 depth 少一层会算成 `ol` 的 pos），要**向上逐层找** `node(depth).type.name === 'listItem'`

## 1. 文本块 `paragraph`

### ① 功能定义
最基础的正文段落，是所有「无特殊语义内容」的默认容器。飞书类名 `.docx-text-block`。

### ② CRUD 闭环

| 操作 | 路径 | 边界 |
| --- | --- | --- |
| 增 | 回车 / 斜杠「正文」/ `turninto → 正文` | 空文本块回车 → 新建同级空块 |
| 改 | 输入 / 行内格式 / 转换为任意块类型 / 缩进 / 对齐 | 支持全部 8 种行内 mark |
| 删 | 空块 `Backspace`（退成上一个块的行尾）/ 块菜单「删除」 | 文档最后一个块删不掉（保底一个空段落） |
| 查 | 查找 / 目录（不进目录）/ 评论锚点 | — |

### ③ 显示与隐藏
- 占位文案：仅文档**末尾空块**显示「输入正文内容，或按 / 键选择」【推导，文案待补】
- `isEmpty` 类名：空块
- `focused` 类名：光标在内

### ④ UI 像素规格【实测】

| 项 | 值 |
| --- | --- |
| 类名 | `.docx-text-block` |
| 尺寸 | **824 × 26**（宽 824 = 正文 820 + 左右负边距各 2） |
| margin | `8px -2px 8px -2px` |
| padding | `0 2px 0 2px` |
| 背景 | `rgba(0,0,0,0)` 透明 |
| 圆角 | `0` |
| font-size / line-height | **16px / 28.8px（1.8）** |
| font-weight | **400**（飞书正文默认不加粗） |
| 文字色 | `#1F2329` |

> ⚠️ **测量陷阱**：曾在该块上读到 14px —— 那是该段被单独设置过小字号。**新输入正文实测 16px**。

### ⑤ 状态与交互

| 状态 | 视觉 |
| --- | --- |
| hover | 块底 `rgba(100,106,115,0.05)`；左侧出现拖拽手柄（层级 79，42×26，radius 6，bg `#FFFFFF`） |
| focused | 加 `.focused` 类，鼠标离开也不显示 hover 底 |
| 选区 | 拖选出现气泡条（594×42，层级 87） |
| 折叠 | 有缩进子块时左侧出现折叠箭头 |

### ⑥ 字段与接口
```json
{ "type": "paragraph", "attrs": { "blockId": "bxxx1", "indent": 0, "lineHeight": null }, "content": [ … ] }
```
无 `attrs` 时 `content` 为空数组即空段落（Tiptap 允许省略 content）。

## 2. 标题 `heading`（H1–H9）

### ① 功能定义
章节标题，是**目录树的唯一来源**，也是**折叠的最小单位**（折叠标题 = 折叠其下整个章节）。飞书支持**九级**（HTML 只到 h6，7–9 级用 `div[data-type="heading"][data-level]` 渲染）。

> 🔴 **结构性重要更正（21.40 实机）：飞书标题是「容器块」，不是叶子块** —— 它会把「直到下一同级标题之间的所有内容」**收进自己的 `heading-children` 内部**：
> ```html
> <div class="block docx-heading1-block">                824×1199（含子内容时被撑高）
> └ <div class="heading-block">                          824×1199
>   ├ <div class="heading heading-h1 heading-block-align-left">   820×36
>   │  ├ <button class="ud__button--text--primary order b">3.</button>  26×20   ← 编号装饰
>   │  └ <div class="heading-content">回归结果</div>              788×36
>   └ <div class="heading-children">                             820×1155   ← 子内容区
> ```
> **对复刻的影响（重要）**
> 1. 块树不要按「扁平块数组 + 缩进级别」建模，应按**标题块嵌套 `children`** 建模 —— 折叠天然是「隐藏子树」，目录天然是「渲染标题树」。
> 2. 若已按扁平数组实现（**lark-doc 现状**：Tiptap `heading` 是叶子节点），需额外维护「每个标题块的子块区间 `[startIndex, endIndex]`」，折叠即批量隐藏，代价更高。
> 3. gutter 三件套（**类型图标 → 拖拽手柄 → 折叠三角**）要做成**块级通用槽位**；折叠槽位只在可折叠块（标题 / 列表 / 引用）启用。
> 4. 对齐态写在 `.heading` 上：`heading-block-align-left|center|right|undefined`（`undefined` = 未设置，用继承值）。

### ② CRUD 闭环

| 操作 | 路径 | 边界 |
| --- | --- | --- |
| 增 | `# `~`######### ` 输入规则 / 斜杠「标题 1-9」/ `turninto → 一~九级标题` / 块菜单 | 气泡条「转换为」只有 10 项：正文 + 一~九级标题 |
| 改 | 直接编辑 / 升降级（`Cmd+]` / `Cmd+[`）/ 开关编号 / 设置编号起点 / 继续编号 | 见下「编号三态」 |
| 删 | 同文本块 | 删除标题**不删其子章节**（子块上提） |
| 查 | **目录树**（唯一进目录的块类型）/ 查找 / 折叠集合 | 目录层级 = heading level |

**标题编号三态**【源码】

| 态 | `numbering` | `numberingStart` | 行为 |
| --- | --- | --- | --- |
| 关 | `false` | `null` | 无编号（飞书新建标题默认） |
| 开·继续 | `true` | `null` | 跟着前序同级标题递增 |
| 开·重排 | `true` | `N` | 从 N 开始，后续递增 |

> 编号是**装饰按钮 + 每帧现算**，**不落进正文文本**。就地输入编号时必须加 `headingNumberApplying` 闸门，否则会与实时重算打架。

### ③ 显示与隐藏
- 目录项：标题非空才进目录；空标题显示为「无标题」【推导】
- 折叠箭头：hover 标题块时左侧出现；折叠后该标题下所有子块隐藏，标题行尾显示「N 个项目已折叠」【文案待补】
- 编号：`numbering === true` 时才渲染

### ④ UI 像素规格【实测】

| 级 | 字号 | line-height | 倍数 | margin |
| --- | --- | --- | --- | --- |
| H1 | **26px** | **36.4px** | **1.4** | `26px -2px 10px -2px` |
| H2 | **22px** | 39.6px | 1.8 | `22px -2px 8px -2px` |
| H3 | 20px | — | 1.8 | `1em -2px 8px` |
| H4 | 18px | — | 1.8 | 同 H3 |
| H5 | 16px | — | 1.8 | 同 H3 |
| H6 | 14px | — | 1.8 | 同 H3 |
| **H7** | **16px** | **22.4px** | **1.4** | **0** |
| **H8** | **16px** | **22.4px** | **1.4** | **0** |
| **H9** | **16px** | **22.4px** | **1.4** | **0** |

> 🔴 **H7–H9 实测【batch99 · Markdown `#`×7/8/9 输入后读 `.ace-line`】**：
> ```
> DIV.heading.heading-h7.heading-block-align-undefined   820×22   margin 0px
> └ DIV.ace-line   820×22   fs 16px / lh 22.4px(1.4) / fw 500 / color #1F2329 / margin 0 / padding 0
> ```
> **三级完全相同**（16 / 22.4 / 500 / margin 0），彼此**无递进**；且 font-weight 是 **500**（H1–H6 为 **400**）。
> 📐 **反直觉**：H6 = 14px 但 **H7 回升到 16px**，且行高倍数从 1.8 降到 **1.4**、margin 归 **0**。即 H7–H9 是"更小一档但更紧凑"的收尾层级，**不要按 H1–H6 的等差规律外推**。
> 📌 文本末尾带一个 **零宽空格 U+200B**（实测 `txt` 尾部有 `​`），是标题容器为了保持空行可编辑而插入的。
> ⚠️ 该值由 Markdown 输入规则产生；用标题下拉（正文 + 一~九级标题，共 10 项）产生的值**未复采**，若后续发现差异以本表为准并注明触发方式。

| 其他项 | 值 |
| --- | --- |
| 类名 | `.docx-heading1-block` … |
| H1 尺寸 | **824 × 36** |
| H2 尺寸 | **799 × 65**（该标题换行了两行） |
| padding | `0 2px` |
| 背景 / 圆角 | 透明 / 0 |
| font-weight | **400**（靠字号区分层级，不加粗） |

> ⚠️ **致命测量陷阱**：`.docx-heading1-block` **容器**读到 `line-height: 46.8px`（= 26 × 1.8）是**继承的无效值**。真实渲染行高必须读行内层 **`.ace-line`**（36.4px = 1.4）。采规格一律读行内层。

### ⑤ 状态与交互
- hover：同文本块（手柄 + 5% 底）
- 目录项 hover/active：见 [03](./03-工具栏与菜单.md) 与 06 的【待补】
- 折叠后：该标题「编号 + 内容」保留，子块 DOM 卸载

### ⑥ 字段与接口
```json
{ "type": "heading",
  "attrs": { "level": 1, "numbering": false, "numberingStart": null, "blockId": "bxxx", "indent": 0 },
  "content": [{ "type": "text", "text": "标题" }] }
```

| 字段 | 类型 | 默认 | 含义 |
| --- | --- | --- | --- |
| `level` | `1..9` | `1` | 级别。`1–6` 渲染 `<h1>~<h6>`；`7–9` 渲染 `<div data-type="heading" data-level="N">` |
| `numbering` | `boolean` | `false` | 是否显示自动编号 |
| `numberingStart` | `number \| null` | `null` | 编号起点；`null` = 继续前序 |
| `blockId` / `indent` | 见 0.3 | | |

## 3. 无序列表 `bulletList` / `listItem`

### ① 功能定义
并列项集合，无序号。飞书类名 `.docx-bullet-list-block`（项 `.docx-list-item-block`）。

### ② CRUD 闭环

| 操作 | 路径 | 边界 |

| 增 | `- ` / `* ` 输入规则 / 斜杠「无序列表」/ `turninto` | 项内 `Enter` → 新建同级项；**空项 `Enter` → 退出列表变文本块** |
| 改 | 项内 `Tab` / `Shift+Tab` 改层级 / 块菜单「缩进」/ marker 点击改符号 | 层级上限见 0.4 |
| 删 | 空项 `Backspace` 退出列表 / 块菜单「删除」 | 删除最后一项 → 整个列表变文本块 |
| 查 | 查找（不进目录） | — |

### ③ 显示与隐藏
- marker（圆点）点击可换符号（飞书有 ● ○ ◆ ▪ 等）【符号集待补】
- 折叠箭头：有子项时显示

### ④ UI 像素规格【实测 + 源码】

| 项 | 值 |
| --- | --- |
| 列表容器 margin | `8px -2px 8px -2px` |
| **顶层列表 padding** | **`0`**（序号顶格对齐正文行首） |
| **嵌套列表 padding-left** | **24px**（逐层） |
| font-size / line-height | **16px / 28.8px（1.8）** |
| marker | `li > p` 内的装饰 widget，随 padding 移动；**关掉原生 `list-style`** |

### ⑤ 状态与交互
- marker hover：浅蓝底 + 下划线【实测，色值待补】
- 折叠、hover、手柄同通用规则

### ⑥ 字段与接口
```json
{ "type": "bulletList", "attrs": { "blockId": "b1" },
  "content": [ { "type": "listItem", "attrs": { "blockId": "b2" }, "content": [ { "type": "paragraph", … } ] } ] }
```
> `listItem` **也在** `BLOCK_ID_TYPES` 里：飞书把列表项当独立块，折叠状态挂在 item 上。

## 4. 有序列表 `orderedList` / `listItem`

### ① 功能定义
带自动序号的列表。飞书类名 `.docx-ordered-block`。序号**每帧现算**，不落死数字。

### ② CRUD 闭环

| 操作 | 路径 | 边界 |
| --- | --- | --- |
| 增 | `1. ` 输入规则 / 斜杠「有序列表」/ `turninto` | 同无序列表 |
| 改 | 缩进改层级 / 序号上「重新开始编号」「设置编号的值」「继续编号」 | 见下 |
| 删 | 同无序列表 | 删除中间项后**后续序号自动接上**（现算机制保证） |
| 查 | 查找 | — |

**「继续编号」语义**【源码】
- item 有起点 → **清掉**起点（恢复自动递增）
- 列表首项 → 给 `ol` 加 `continueFrom`，接上一个**紧邻** `ol`

> ⚠️ 菜单 `canContinue` 必须读**实时 `editor.state`**，不能闭包捕获旧 state（widget DOM 会复用，闭包里的 state 是旧的）。

### ③ 显示与隐藏
- 序号点击弹出菜单：重新开始编号 / 设置编号的值 / 继续编号
- 就地输入序号（弹小输入框）→ 需 `headingNumberApplying` 闸门

### ④ UI 像素规格【实测】

| 项 | 值 |
| --- | --- |
| 容器尺寸 | **824 × 26** |
| margin / padding | `8px -2px` / `0 2px` |
| font-size / line-height | **16px / 28.8px（1.8）** |
| 顶层 `ol` padding | **0**；嵌套 24px |

### ⑤ 状态与交互
- 序号 hover：浅蓝底 + 下划线
- `data-tooltip` 气泡靠序号自身 `position: relative` 定位（不要挂到父级）

### ⑥ 字段与接口
```json
{ "type": "orderedList", "attrs": { "blockId": "b1", "continueFrom": false },
  "content": [ { "type": "listItem", "attrs": { "blockId": "b2", "numberStart": null }, "content": […] } ] }
```

  content: '';
  position: absolute;
  left: 0;
  top: 0;
  width: 2px;

| `position` | `absolute` |
| `left` / `top` | `0` / `0` |
| **`width`** | **2px**（不是推测的 3px） |
| **`height`** | **26px**（= 该引用块实测高，随内容变） |
| **`background-color`** | **`rgb(187,191,196)` = `#BBBFC4`** |

| **外层 chip** | `span.inline-code.inline-code_start.inline-code_end` | **35 × 24** | **`rgb(245,246,247)` #F5F6F7** | **`1px solid rgb(222,224,227)` #DEE0E3** | **`4px`** | **`1px 0`** | **`0 3px`** | `SourceCodeProMac` |
| **内层文本** | 无类名 `span` | 33 × 20 | 透明 | 无 | **`3px`** | **`0 2px`** | `0` | `SourceCodeProMac` |

**文字样式**：fs **16px** / lh **26px**（与正文一致）/ fw **400** / color **`rgb(31,35,41)`**

**📐 尺寸推导**

- 外层宽 = 内层宽 + 2×1(border) → `35 = 33 + 2` ✅
- 外层 margin `0 3px`：**左右各外扩 3px**，所以整段行内代码的**视觉占位 = 内容 + 6 + 2**
- 外层 padding 只有纵向 `1px`：横向留白由内层 `0 2px` 承担 → **别在两层都写横向 padding**，会翻倍
- 高度 24 vs 文本 20：`1px pad ×2 + 1px border ×2 + 20 = 24` ✅

**🔑 三个坑**

1. **`_start` / `_end` 是区间类名**：飞书用 `inline-code_start` / `inline-code_end` 标记连续行内代码的**首尾片段**（跨选区拆成多个 span 时只有首尾带）。复刻时若自己实现，需要保留这三个类名以便视觉连续（避免每个片段都画左右圆角边框）。
2. **两层圆角不同**：外层 4px、内层 3px。只写外层会显得内层「贴边」。
3. **字体是 `SourceCodeProMac` 而不是 `monospace`**：与代码块同族，需在字体栈里显式声明，否则落到系统等宽会宽窄不一。

#### ④-3 链接 `link` 行内规格【实测 2026-10-24 · batch116/118 · `Cmd+K` 落链接后读 DOM】

**真实 DOM（三层嵌套，不是裸 `<a>`）**

```html
<span class="outer-u-container docx-outer-link-container link-underline">   ← 画下划线的外层
  <span class="link-wrapper link-text-color link-start link-end">           ← 字色/片段标记层
    <a class="link contextmenu-without-copyperm" href="…" target="_blank">   ← 真链接
      <span>链接文字</span>
    </a>
  </span>
</span>
```

| 元素 | 关键样式【实测】 |
| --- | --- |
| 文字色 | **`rgb(51,109,244)` = `#336DF4`**（与 Tab 选中色、封面 Tab、列表序号同源） |
| 下划线 | 外层 `.link-underline` 上 `text-decoration-line: **underline**`，**常驻**（不是 hover 才出现）；`text-decoration-color` 同为 **`#336DF4`** |
| 光标形状 | `cursor: pointer` |
| 权限相关类 | `a.link.contextmenu-without-copyperm`（无复制权限时带此后缀，右键菜单不出现「复制链接」） |
| 区间类 | `link-start` / `link-end` —— 与行内代码 `_start/_end` 同理，标记**连续链接被拆成多段时的首尾** |
| 字号/行高 | **继承上下文**（实测在代码块行内为 14px/22px，在正文为 16px/28.8px）→ **链接不覆盖字号行高**，只覆盖颜色与下划线 |
