# 04 · 浮层与弹窗（Overlay / Popover / Drawer / Dialog）

> 覆盖飞书文档**所有浮层类 UI** 的尺寸、层级、显隐与闭环。命令条（气泡条 / 块手柄 / 斜杠菜单）详见 [03-工具栏与菜单.md](./03-工具栏与菜单.md)，本节只做交叉引用与层级补齐。
>
> 【实测】= 飞书实机 `getComputedStyle`/`getBoundingClientRect`；【待补】= 未采到。

## 0. 通用：飞书浮层四件套

飞书把浮层分成**四个组件族**，复刻时应按族实现而不是逐个写。

| 族 | 类名前缀 | 语义 | 是否有遮罩 | 典型 |
| --- | --- | --- | --- | --- |
| **Popover** | `ud__popover` | 跟随锚点的小浮层 | 无 | emoji、代码语言、公式编辑器、日期提醒 |
| **Overlay 命令条** | `overlay-container` + `docx-menu-wrapper` | 命令菜单 | 无 | 气泡条、块手柄菜单、斜杠菜单、图片工具条 |
| **Drawer** | `ud__drawer` / `ud__drawer-right` | 侧边抽屉（全高） | 有 | 快捷键面板 |
| **Dialog** | `ud__dialog` + `ud__modal` | 居中模态框 | 有 | 关联多维表格、Jira 弹窗 |

### 0.1 浮层通用 DOM 骨架【实测】

```html
<!-- Popover -->
<div class="ud__popover [equation-editor-popover] web ud__popover--mode-normal" style="position:fixed">
  <div class="ud__popover-content">…</div>
</div>

<!-- 命令条 Overlay -->
<div class="overlay-container" style="position:fixed; z-index:87">
  <div class="docx-menu-wrapper">      <!-- 白底 + radius 6 + shadow rgba(31,35,41,0.1) 0 4px 8px 0 -->
    <div class="docx-menu-container">  <!-- padding 8 -->
      <div class="panel-menu-item" data-name="…">…</div>
      <div class="menu-divider-item"></div>
    </div>
  </div>
</div>

<!-- Drawer -->
<div class="ud__drawer ud__drawer-right ud__drawer-open">   <!-- 宽 314，全高 -->
  <div class="ud__drawer__close">…</div>                     <!-- 24×24 -->
  <div class="ud__drawer__content__pd-md ud__scrollArea">…</div>
</div>

<!-- Dialog -->
<div class="ud__dialog__mask appear-done enter-done">        <!-- 1512×950 遮罩 -->
  <div class="ud__dialog__wrap ud__dialog--centered">
    <div class="ud__dialog__content ud__modal ud__dialog__content-xl" role="dialog" aria-modal="true">
      <div class="ud__modal__content"><div class="ud__modal__body">…</div></div>
    </div>
  </div>
</div>
```

### 0.2 浮层通用关闭行为

| 触发 | 行为 |
| --- | --- |
| `Esc` | 关闭**最上层**浮层；多层时逐层退出 |
| 点击浮层外部 | 关闭（Dialog 需点遮罩） |
| 浮层内操作完成 | 多数自动关闭；表单类（按钮配置 / 关联表格）需点「确定」 |
| 滚动文档 | 跟随锚点的 Popover 重新定位；命令条通常**直接关闭** |
| 编辑器失焦 | 命令条关闭；评论面板保留 |

**3 项清单（顺序固定）**

| # | 文案 | 图标颜色 | 行为 |
| --- | --- | --- | --- |
| 1 | **选择图片** | `rgb(43,47,54)` #2B2F36 | 换成 **542×522 图库面板**（见 §1.4.3） |

**📐 像素推导（可直接写死）**

- 面板 `162×126`：`宽 = 160 + 2×1(border)`；`高 = 124 + 2×1(border)`
- 列表高 `124 = 8(top pad) + 3×36 + 8(bottom pad)` ✅
- 项间**零间隙**（353 → 389 → 425，步距 = 36 = 项高）
- 图标到文字 **20px**（icon 右缘 1335 → 文字左缘 1355）
- 项内左缩进 **16(padding) + 4(icon margin) = 20**（面板左缘 1294 → 图标 1315，差 21 含 1px border）
- **锚点**：面板 top **344** = 按钮 top 309 + 按钮高 30 + **5**；面板右缘 1456（距视口右 56）

**🔑 三个易错点**

1. **遮罩是全屏透明层**：`.overlay-mask` 1512×950 **z78**、`rgba(0,0,0,0)`。只负责「点外部关闭」，**不做压暗**。复刻时若给它加背景色，整页会变灰。
2. **z 差只有 2 级**：面板 80 / 遮罩 78。别按 Dialog 的 1000+ 惯例写。
3. **面板带 1px 边框**：`#DEE0E3` 与表格网格线同色；只有 shadow 没有边框会显得「浮不起来」。

> ⏳ 项 hover 底色未采（`li` 静止态 bg 全透明），按 §0 通用规则取 `rgba(31,35,41,0.1)` 或 `#F2F3F5`，下一轮 hover 复采确认。

// 浮层组件入参
interface LangPickerProps {

#### ⑥ 字段与接口
