# 16 · 无障碍与国际化（A11y / i18n）

> **本文件定位**：`15 §9.1` 矩阵里 **D9（无障碍）** 与 **D10（国际化）** 的实测记录与复刻口径。
> 结论来源：`batch541`（全页普查）+ `batch542`（细节补齐 + 正反向 Tab 遍历），实际运行于真实飞书文档 `.../wiki/Dx6Pw1gKUiKENjkipsPcmU3DnGg`（页面 `/code`）。
>
> ⚠️ **一句话结论**：**飞书文档的编辑器正文几乎没有做无障碍。** 复刻时不能「照抄飞书」，否则复刻出来的东西同样是不可访问的；必须**在飞书的视觉与交互之上自建一层 a11y 语义**（§5 给出最小可用口径）。

## 1. batch541 · 全页普查（D9 首探）

**脚本**：`~/codex/feishu-recon/batch541.mjs`（`EXIT=0` / 23s）

### 1.1 角色与 ARIA 总量

```
roles = {"n":22, "dist":{"button":14, "list":2, "item":4, "dialog":1, "faster":1}}
aria.counts = {
  aria-label 0, aria-hidden 0, aria-expanded 0, aria-selected 0,
  aria-modal 1, aria-level 0, aria-checked 0, aria-disabled 1,
  aria-controls 0, aria-labelledby 0, aria-describedby 0, aria-live 0,
  aria-current 0, aria-haspopup 0, aria-required 0, aria-invalid 0

aria.labels = []          ← 全页一个 aria-label 都没有

```

**读法**：22 个 role 里 14 个 `button`、2 个 `list`、4 个 `item`、1 个 `dialog`，**全部在左侧目录树**（`base-styled__HoverableWrapper` / `trigger-styled__TriggerWrapper`）。正文 820px 宽的编辑器里 **0 个 role**。

### 1.2 块级属性（关键：只有一个属性）

```
blockA11y = [
  {t:"page",   tag:"div", attrs:{"data-block-type":"page"},   outline:"none", userSelect:"auto"},
  {t:"text",   tag:"div", attrs:{"data-block-type":"text"},   outline:"none", userSelect:"auto"},
  {t:"bullet", tag:"div", attrs:{"data-block-type":"bullet"}, outline:"none", userSelect:"auto"},
  {t:"ordered", none:true},
  {t:"todo",   tag:"div", attrs:{"data-block-type":"todo"},   outline:"none", userSelect:"auto"}, …
]
```

⇒ 每个块是 `div` + **唯一一个 `data-block-type`**。没有 `role`、没有 `aria-label`、没有 `tabindex`、没有 `aria-level`（`aria-level: 0` 证实层级信息完全不在 DOM 里）。

### 1.3 可编辑根

```
rootAttrs = [
  {".ProseMirror": none},        ← 不是 ProseMirror 渲染
  {".docx-editor":  none},
  {"[contenteditable=true]": {tag:"div",
     class:"page-block root-block",
     "data-slate-editor":"true",          ← Slate 系
     contenteditable:"true",
     spellcheck:"false",
     "data-content-editable-root":"true"}}
]
```

⇒ **`spellcheck="false"`**（关掉拼写检查，无 `aria-invalid` 场景），`role` / `aria-multiline` / `aria-label` 一概没有。

### 1.4 焦点环

```
focusRing_bar  = {before:{outline:"none 3px rgb(100,106,115)", offset:"0px", shadow:"none", border:"0px none rgba(0,0,0,0)"},
                  after: 同值} → changed:false
focusRing_root = {before:{outline:"solid 0px rgba(0,0,0,0)", border:"0px none rgb(31,35,41)"},
                  after: 同值} → changed:false
```

⇒ **飞书的焦点态不是用 `outline` 做的**（按钮 `outline: none 3px`，即宽度存在但样式 none），`focus()` 前后计算样式完全不变。视觉上的 hover/focus 全部走 `background-color` 的 class 切换（见 `06` 的 `--ud-*` 变量）。**结论：无法从飞书抄焦点环 token，必须自定。**

### 1.5 Tab 序

```
tabOrder = 26 条，每一条都是：
  {tag:"div", cls:"page-block root-block", aria:null, title:null,
   txt:"添加图标 /code 崔健", r:[331,347,820,1141]}
```

⇒ **编辑器是单一 Tab 陷阱**：进入后无论按多少次 Tab 都出不来，焦点永远落回同一个 contenteditable 根。这对键盘用户是硬阻断（无法跳到顶栏按钮、无法跳转到侧栏）。

### 1.6 动效与 reduced-motion

```
anim_after_scroll_scan = {scanned:1583, anim:3, trans:64,
  samples:[{ad:"2s",  cls:"ud__illustration__loading-container"},
           {ad:"0.5s",cls:"text-block-wrapper animation-indent--rig"},
           {ad:"0.2s",cls:"block-tips-tooltip__container"}]}
anim_with_reduced      = {scanned:1574, anim:1, trans:64}
anim_delta             = {anim:-2, trans:0}     ← 只少了 2 个动画，transition 一个没少
motionDecl             = {sheetsOk:106, sheetsDenied:88, reducedMotionRules:12}
```

**读法**：`emulateMedia({reducedMotion:'reduce'})` 只干掉了 2 个 animation（`animation-indent--rig`、`block-tips-tooltip__container`），**64 个 transition 一个都不降级**。而 12 条 `@media (prefers-reduced-motion: reduce)` 规则的内层 selector 全是 bitable 模块私有的（见 §2.4）。

### 1.7 其他

```
dataTooltipN = 0        ← 正文没有任何 data-tooltip（飞书的 tooltip 走 runtime 浮层，见 04）
moreBtn      = null     ← 「更多」按钮定位失败，浮层 aria 抽查未跑（→ batch543 补）
```

### 2.8 `role="faster"` 定判（batch543/544）

```
faster = [{ role:"faster", tag:"canvas", cls:"", r:[331,1270,599,168], vis:true, txt:"",
   attrs:["faster=1","role=faster","issupportcustomtheme=false","tabindex=-1","width=599","height=168", …],
   html:"<canvas faster=\"1\" role=\"faster\" issupportcustomtheme=\"false\" tabindex=\"-1\" width=\"599\" height=\"168\"
          style=\"…image-rendering: pixelated; background-color: transparent; user-select:none; -webkit-user-drag:none…\">" }]
```

⇒ **是一个 `<canvas faster="1" role="faster" tabindex="-1">`**：
- **`faster` 不是任何 ARIA 标准 role**（WAI-ARIA 1.2 词汇表里没有），是飞书内部给 canvas 打的**自造标记**；
- 空文本、无 class、`tabindex="-1"`（不可 Tab 到）、`image-rendering: pixelated`；
- 尺寸 `599×168` / `820×168`，位置在正文列内（x=331）；
- **出现时机**：页面常驻 1 个（`roleMap.faster.inBody = 1`），斜杠菜单打开时也在（说明不是浮层专属）。

**判定**：**对辅助技术完全无意义**（自造 role，屏幕阅读器会忽略或读成未知角色）。它不是 a11y 资产，是渲染层标记（大概率是「性能降级模式」或「纹理缓存」的开关）。**复刻时不要抄这个 role。**

### 2.9 真实浮层：`role` 全是「离屏预热池」，真弹出的是裸 `div`（batch543/544）

这是 D9 最反直觉的一条，必须单独记：

```
// A. 抓到的 role=menu 全在视口外 8500px
bubble_aria / slash_aria → total 24，全部 {
  ul.cls:"ud__menu-normal ud__menu-normal-root …", attrs:{role:"menu", tabindex:"0"},
     r:[-8545, -9123, 120, 166], txt:"上传日志 联系客服 功能更新 帮助中心 快捷键"
  li.cls:"ud__menu-normal-item …", attrs:{role:"menuitem", tabindex:"-1"},
     r:[-8541, -9119, 112, 30]
}
// B. 真实弹出来的斜杠面板（Esc 前）
slashOvl → { tag:"div", attrs:{data-e2e:"slshpnl", class:"overlay-container overlay-transition"},
             z:"600", pos:"fixed", r:[380,149,232,639], vis:true,
             innerRoles:[], innerAria:[] }        ← 里面 0 个 role、0 个 aria
// C. Esc 后面板从浮层根里消失（关得掉）
slash_after_esc_roots → slshpnl 已不在列表
// D. 全局浮层 portal 容器
ovlContainers_static → { tag:"div",
   attrs:{class:"global-overlay-container disabled-contextmenu ccm-scope", "data-custom-shortcut-area":"1"},
   z:"auto", pos:"static", r:[0,950,1512,0] }      ← 0 高度挂载点，无 role
```

**读法（关键）**：
1. 飞书有一套 `ud__menu-normal` 组件（**自带 `role="menu"` / `role="menuitem"` / `tabindex`**），但它是**离屏预热的实例池**（`x=-8545, y=-9123`），只有在某个 `um__trigger` 真的用到它时才搬进视口；
2. **斜杠面板 `/`（84 项）根本不是这套组件** —— 它是 `div.overlay-container[data-e2e=slshpnl]`，里面 `innerRoles: []` / `innerAria: []`，**84 个条目一个 role 都没有**；
3. 所以「飞书有 `role=menu`」是**假象**：真的有 role 的菜单是「帮助中心」那种顶栏下拉，编辑器里最核心的 `/` 菜单反而是零语义裸 div。

**对照：该 feature 键盘可用但屏幕阅读器不可见**：

```
slashActiveEl  = div.page-block root-block（焦点始终留在编辑器，未进入面板）
slashKbdMove   = {"activeDesc": 0, "hl": []}     ← 无 aria-activedescendant、无高亮底色可扫
slashKbdInsert = {… text: 9→11, heading2: 1 …}   ← 但按 ↓↓ + Enter 真的插入了块
```

⇒ **结论**：`/` 菜单是「键盘能操作、AT 完全看不见」的典型。`ArrowDown` 的选中态**不写进 DOM**（既无 `aria-activedescendant`，也无 class 切换以外的可读数），所以屏幕阅读器无法播报当前选中项。

### 2.10 编辑器焦点真实宿主 = 离屏 `readonly` textarea（batch543/544）

```
esc_focus    = { before:{tag:"div", cls:"page-block root-block", role:null},
                 after: {tag:"textarea", cls:"docx-selection-hidden-textarea", role:null}, same:false }

ime = [{ cls:"docx-selection-hidden-textarea",
   attrs:{class:"docx-selection-hidden-textarea", readonly:"",
          style:"position:fixed; top:0; left:-100px; opacity:0; width:2px…",
          "data-current-root-block-id":"1"},
   r:[-100, 0, 2, 950], pos:"fixed", op:"0", tab:null, aria:null,
   parent:"layout-column ccm-scope wiki" }]
```

⇒ 飞书的输入链路是 **「离屏 `readonly` textarea 承接 IME 合成 → 再回写 Slate」**。这个 textarea：
- `position: fixed; left: -100px; opacity: 0`，**2px 宽 × 950px 高**（撑满视口高度，为了让 IME 候选框定位正确）；
- **`readonly`** —— 它只收 composition 事件，不存内容；
- **无 `tabindex`、无 `aria-label`** ⇒ 对 AT 而言它是个「不可聚焦的透明文本框」。

**这解释了 1.5 的单一 Tab 陷阱**：`document.activeElement` 在编辑器内部被这个 textarea 代理，contenteditable 根只是「看起来」有焦点，所以 Tab 永远在两者之间打转。

**复刻口径**：ProseMirror/Tiptap **不需要**这层代理（Tiptap 直接监听 contenteditable 的 composition 事件），所以复刻时反而**更容易做对 Tab 序** —— 这是「不复刻飞书」能白赚的一处。

### 2.11 表块零语义的根因：bitable 是 **canvas 画的**（batch544）

```
bitableHost = { r:[331,1252,820,220], iframes: [], shadowCount: 0, shadow: [],
                childTags: ["div","span","svg","path","canvas"] }

table_after_scroll.semantic = { table:0, thead:0, th:0, td:0,
   roleTable:0, roleGrid:0, roleRow:0, roleCell:0, ariaRowCount:0 }

// 块本体只有一个 div + 三个 data 属性：
<div class="block docx-bitable-block" data-block-type="bitable" data-block-id="34" data-record-id="doxcnam6u8…">
  <div class="bitable-block-container BASE_BLOCK_COPY_CONTAINER …" contenteditable="false" data-origin-token="PWX7bd…">
```

⇒ 表块**既不在 iframe 里、也不在 shadowRoot 里**，`childTags` 里直接有 **`canvas`** ⇒ **多维表格的内容是 canvas 绘制**。这比「用 div 模拟表格」更彻底：**DOM 里连单元格文字都不存在**，屏幕阅读器 / 全文检索 / 复制 全部拿不到。

**判定**：表块 a11y = **零**（连补救的钩子都没有）。复刻 V1 如果也用 canvas 渲染表，必须**额外提供一份 `sr-only` 的语义镜像**（`<table role="table">` + 单元格文本），否则表内容对 AT 完全不可见。

## 5. V1 复刻口径（最小可用 a11y）

> 目标：**不是超过飞书，而是不把飞书的坑带过来。** 下面每一条都是「飞书没做、我们补」的增量。

### 5.1 必须自建的 6 件事

| # | 项 | 具体做法 |
| --- | --- | --- |
| 1 | 编辑器根语义 | `role="document"` + `aria-multiline="true"` + `aria-label="文档正文"`（`aria-labelledby` 指向标题块 id） |
| 2 | 块级语义 | 每个块 `div` 加 `role="paragraph"`（文本）/ `role="heading"` + `aria-level`（标题 1–9）/ `role="listitem"`（列表）/ `role="checkbox"` + `aria-checked`（待办）/ `role="figure"` + `aria-label`（图片/画板） |
| 3 | 列表结构 | 列表容器 `role="list"`，子项 `role="listitem"`；**嵌套层级用 `aria-level`**（飞书 DOM 里 `aria-level: 0`，彻底缺失） |
| 4 | Tab 序 | 编辑器**只作为 1 个 Tab 停靠点**，内部用方向键 / `Ctrl+↑↓` 走块（这是 Notion/飞书的真实键盘模型，但飞书没做 Tab 逃逸）；**`Esc` 必须能把焦点送回顶栏** |
| 5 | 焦点环 | 自定 token：`outline: 2px solid var(--ld-focus-ring)` + `outline-offset: 2px`，`--ld-focus-ring` 建议取飞书主色 `#3370FF` 的 70% 透明版；仅 `:focus-visible` 生效 |
| 6 | 地标 + skip-link | 顶栏 `role="banner"`、侧栏 `role="navigation"`、正文 `role="main"`；首个可聚焦元素放 `<a href="#editor">跳到正文</a>`（`sr-only`，聚焦时显现） |

### 5.2 `aria-label` 的粒度（飞书 0 个，我们至少要 5 类）

| 对象 | 建议 label |
| --- | --- |
| 顶栏图标按钮 | `aria-label="标题级别"` / `"加粗"` / `"插入"` / `"更多"`（**图标按钮必须有，这是最低要求**） |
| 拖拽手柄 | `aria-label="拖动 <块类型>"` + `role="button"` |
| 块菜单触发器 | `aria-label="块操作菜单"` + `aria-haspopup="menu"` + `aria-expanded` |
| 折叠箭头 | `aria-expanded="true|false"` + `aria-label="折叠/展开"` |
| 待办框 | `role="checkbox"` + `aria-checked` + `aria-label=<待办文本>` |

### 5.3 动效降级（飞书只覆盖 bitable）

```css
@media (prefers-reduced-motion: reduce) {
  /* 飞书没做的、我们要做的 */
  .ld-synced-source-children { transition: none; }     /* 飞书 1s opacity */
  .ld-tooltip                { animation: none; transition: none; }
  .ld-block-indent           { transition: none; }     /* 缩进动画 */
  .ld-collapse-arrow         { transition: none; }
  .ld-at-user                { transition: none; }     /* 飞书 0.3s color */
}
```

**9 个动画开关**（与 `06 §动效` 对齐）：① 标题级别下拉展开 ② 块菜单出现 ③ 气泡条出现 ④ 拖拽 ghost ⑤ 落点指示线 ⑥ 折叠/展开箭头旋转 ⑦ 缩进位移 ⑧ 同步块展开 ⑨ 数字角标更新。
