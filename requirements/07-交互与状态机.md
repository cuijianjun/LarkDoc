## 1. 文档模式状态机（三态，不是二态）【实测】

飞书文档是**三种交互模式**，不是「只读/可编辑」二态。入口：顶部「编辑」按钮（`docs_mode_switch_dropdown_btn`，x=1130, y=32），**下拉式**而非普通 toggle。

```
        ┌──────────┐
        │   编辑   │  ← 默认；完整编辑权限
        └────┬─────┘
   ┌─────────┼─────────┐
   ▼                   ▼
┌────────┐        ┌────────┐
│  修订   │        │  阅读   │
└────────┘        └────────┘
提出修改建议        仅查看或评论
需他人接受/拒绝     只读，仅可评论
```

| 模式 | 快捷键 | 可编辑正文 | 可插入块 | 可评论 | 气泡条 | 块手柄 | 拖拽 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| **编辑** | `E` / `Ctrl+⌥+E` | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| **修订** | `⌘+⌥+X` | ⚠️ 变修订建议 | ⚠️ | ✅ | ✅ | ✅ | ⚠️ |
| **阅读** | `Ctrl+⌥+V` | ❌ | ❌ | ✅ | ❌ | ❌ | ❌ |

> 复刻要点：「修订」是**独立的第三态**（改动以「修订建议」形式落地，需他人接受/拒绝），不能简化成编辑态的一个开关。
> **修订态的完整规格（标记 DOM / 建议面板 270 宽 / 6 个头部按钮 / 接受·拒绝行为）见 [§12](#12-修订模式suggest-mode完整规格实测-batch157158159160)。**

## 2. 权限状态机（能力位驱动 UI）

| 能力位 | 缺失时的 UI 表现【实测】 |
| --- | --- |
| 复制权限 | 目录项加 `contextmenu-without-copyperm` → **右键菜单静默禁用**（不弹空菜单）；查找替换面板加 `without-copyperm-dom` → 隐藏部分能力 |
| 评论权限 | 气泡条 `comment` 项隐藏 |
| 版本权限 | 历史记录「还原此历史记录」按钮禁用（见 [05](./05-接口文档.md) `can()` 闸门） |
| 分享/管理权限 | `canManagePermission` 默认 **false** |

> **判定规则**【源码】：`can(key)` = `capabilities[key] !== false`（即**只有显式 `false` 才算禁用**），且异步取能力失败时**不炸**，回落默认。见 [05](./05-接口文档.md) §authorization。

## 3. 块状态机

### 3.1 块的四个互斥视觉态

| 态 | 类名 | 触发 | 清除 |
| --- | --- | --- | --- |
| 常态 | — | — | — |
| hover | 无独立类名（CSS `:hover` 或 JS 加类） | 鼠标在块区域 | 鼠标离开 |
| **focused** | `.focused` | 光标在块内 | 光标离开 |
| **isEmpty** | `.isEmpty` | 块内容为空 | 输入任意字符 |
| 选中（多块） | 拖选跨块 | 拖选 / `Cmd+A` | 点击别处 / `Esc` |

**叠加规则【实测】**
- `focused` 时**不叠加** hover 底（避免光标块看起来一直 hover）
- `isEmpty` 与 `focused` 可共存 → 显示占位文案
- 容器块（高亮/引用/表格）内部子块也可各自 `focused`

### 3.2 gutter 槽位（块左侧控件）【实测】

**顺序从左到右固定**：类型图标 → 拖拽手柄 → 折叠三角

| x（相对 heading 左边距 604） | 元素 | 尺寸 | 适用范围 |
| --- | --- | --- | --- |
| 545 | `.overlay-container.overlay-transition` > `.menu-trigger.{type}-menu-trigger.has-drag-icon` > `.hover-drag-icon-wrapper` | **42 × 26**，bg `#FFFFFF`，radius 6 | 全部块（层级 **79**） |
| 547 | `.hover-block-type-icon-container` > `span.universe-icon` | 24×24（图标 22×22） | 全部块 |
| 571 | `span.universe-icon.drag-handle` | **14 × 14** | 全部块 |
| **587** | **`.fold-handler` > `.svg-wrapper` > svg** | **16 × 16** | **仅可折叠块**（标题 / 列表 / 引用） |

- 三角右边缘距块左边 **1.75px**
- `menu-trigger` 变体类跟随块类型：`heading1-menu-trigger` / `ordered-menu-trigger` / `image-menu-trigger` / `file-menu-trigger` / `text-menu-trigger`
- 折叠三角是**标题块独有**的第三个 gutter 控件（普通文本块只有前两个）

### 3.3 折叠状态机

```
展开 ──点击三角──► 折叠 ──再点──► 展开
  │                  │
  │                  └─► .heading-children 隐藏（标题自身保留）
  │                  └─► 目录对应项加 catalogue__item-collapse.collapsed
  │
  └─► 折叠状态按 blockId 持久化
```

| 规则 | 说明 |
| --- | --- |
| 折叠单位 | **标题块**（含其 `heading-children` 子树）；列表项；引用 |
| 状态存放 | **挂在 `blockId` 上**，不是位置索引（增删块后仍对得上） |
| 与目录的关系 | **两套独立状态**，可分别折叠（飞书实测） |
| 持久化 | 三闸门（见 [05](./05-接口文档.md)） |
| 折叠后 | 子块 DOM 卸载（虚拟渲染） |

> ⚠️ 复刻踩坑：折叠范围 = **缩进子树**（非标题专属）；文本块后的**未缩进列表是隐式子块**，但 `previousIndent` 要用**原 indent**。

### 3.4 拖拽块（drag & drop）状态机与落点指示【实测 · batch137/139/142/145】

#### 3.4.1 三态流转

```
idle ──鼠标进入块左缘 gutter（x ≈ 块左 − 60 ~ 块左）──► handle-visible
handle-visible ──mousedown 于 .drag-handle──► dragging（位移 > 5px 才真正启动）
dragging ──mouseup──► 落点提交 ──► idle
dragging ──Esc──► 取消（源块恢复，DOM 无残留）
```

| 态 | DOM 证据 | 视觉 |
| --- | --- | --- |
| `handle-visible` | `.overlay-container.overlay-transition`（42×26，z **79**）挂载 | 白底圆角 6 手柄浮现（见 §3.2） |
| `dragging` | 源块加类 `dragging`，`opacity: 0.5` | 原位半透明占位 |
| `dragging` | 新增 `div.adit-draggable-snapshot-container`（`position: absolute`，**z-index 9999**） | 跟随光标的「影子块」 |
| `dragging` | 新增裸 `div`（无 class）作为**落点指示线**（`position: absolute`，**z-index 10**） | 2px 蓝色横线 |

#### 3.4.2 影子块（snapshot）规格

| 属性 | 值 |
| --- | --- |
| 容器 | `div.adit-draggable-snapshot-container` |
| 尺寸 | = 源块宽 × 源块高（实测 **824 × 29**） |
| 定位 | `absolute` @ (578, 681)（相对文档容器） |
| z-index | **9999** |
| 内部结构 | `wrapper.block.docx-text-block.dragging` → `block.docx-text-block.drag-snapshot` → `text-block-wrapper` + `hovered-mask` |
| `hovered-mask` bg | `rgba(20, 86, 240, 0.1)` = **#1456F0 @10%** |
| 顶层拖拽层 | `body` 末尾还有一个 `position: fixed; z-index: 99999` 的裸 `div`（1512×950），**不承载可见内容**，仅作事件/定位容器 |

#### 3.4.3 落点指示线规格（B21 核心）

| 属性 | 值 |
| --- | --- |
| 元素 | **裸 `div`，无 class、无 id、无 data-\* 属性** → 只能按「2px 高 + 蓝色 + absolute」特征定位 |
| 尺寸 | **高 2px**；宽 = 内容列宽（实测 **822**，另一档 **820**） |
| 左缘 x | **605**（另一档 **607**）；右缘恒为 **1427**（右端不随落点变化） |
| 颜色 | `background: rgb(51, 109, 244)` = **#336DF4**（与主色同源，**不是** #1456F0） |
| 圆角 / 投影 | `border-radius: 0px`、`box-shadow: none` |
| 伪元素 | `::before` / `::after` 均为 `content: none` → **左端没有圆点/小方块**（与 Notion 风格不同，复刻时不要加） |
| 定位 | `position: absolute; z-index: 10` |
| 触发范围 | **仅在光标接近块边界时出现**；光标停在块垂直中部时**指示线不渲染**（实测 y=420/500/610/700 四个采样点全部无指示线） |
| 跟随性 | 落点跟着最近的块边界跳变，**不连续滑动**（实测只在 325 与 1010 两个边界出现过） |
| 自动滚动 | 拖到底部（y ≥ 860）触发自动滚动后，指示线 y 会随滚动改变（实测 1010）→ 复刻时指示线坐标须每帧重算 |

**复刻口径（推荐实现）**

```css
.drop-indicator {
  position: absolute;   /* 相对文档容器，不用 fixed */
  z-index: 10;
  height: 2px;
  background: #336DF4;
  border-radius: 0;
  box-shadow: none;
  pointer-events: none;
}
```

```js
// 每次 dragover 重算：找最近的块边界，把指示线贴上去
const gap = nearestBlockGap(pointerY);        // 上边界 or 下边界
indicator.style.top  = gap.y + 'px';
indicator.style.left = contentLeft + 'px';    // 605
indicator.style.width = contentWidth + 'px';  // 822
```

#### 3.4.4 仍未验证（复刻可先用默认策略）

| 项 | 现状 | 暂用策略 |
| --- | --- | --- |
| 落点指示线的**缩进变体**（拖到列表项内部 → 线是否左缩进 + 变短） | ❌ 未采到。横向移动 0/80/160/240/320/420px 时指示线均在 605/607 两档间跳动，未出现按 24px 步进的缩进值 | 按 `indent × 24px` 缩短线宽、右移左缘 |

## 4. 选区状态机

```
光标态（collapsed）
   │  拖选 / Shift+方向 / 双击（选词）/ 三击（选段）
   ▼
文本选区态
   ├─► 出现气泡条（594×42，z 87）
   ├─► 出现字数统计气泡（27×25，z 60）
   └─► 字数 = 选区字符数
   │  Esc / 点击别处 / 输入
   ▼
回到光标态
```

| 事件 | 结果 |
| --- | --- |
| 双击单词 | 选中该词 |
| 三击段落 | 选中整段 |
| 单击图片 | **只选中块**，唤起 `block-toolbar__overlay`（310×42） |
| **双击图片** | 进入大图预览（`docx-image-viewer-shell`，z 1049） |
| **单击链接** | **新标签页打开**（batch116：当前 URL 不变、`pages` 1→2），hover 卡随之关闭 |
| **hover 链接** | ≥1.2s 后浮出**链接卡 440×42 z999**（URL + 铅笔 `edit-link` + 垃圾桶 `delete-ink` + 「标题视图」+ 更多）；**编辑必须点铅笔，不能单击** |
| **选中文字 + `Cmd+K`** | 浮出**链接编辑条 434×82 z600**（占位「粘贴或输入链接」，回车或点「确认」落链接）；**粘贴 URL + 空格不会自动转链接** |
| 拖选跨块 | 多块选中；气泡条仍显示（作用于文本部分） |

> ⚠️ 复刻踩坑：触发气泡条要用**真实鼠标拖选**（`mouse.move → down → move(steps) → up`），比 `Shift+方向键` 可靠。

## 5. 浮层栈状态机

```
无浮层
  │ 触发（点击 / 快捷键 / 输入 @ / 输入 / ）
  ▼
浮层栈 [A]
  │ 触发子菜单
  ▼
浮层栈 [A, B]        ← B 的 z-index 更高（子菜单 600 > 命令条 87）
  │ Esc / 点外部
  ▼
浮层栈 [A]           ← 逐层退出，不是一次全关
  │ Esc / 点外部
  ▼
无浮层
```

| 规则 | 说明 |
| --- | --- |
| Esc | 只关**栈顶**；栈空时 Esc 无副作用 |
| 点外部 | 关闭**整个栈**（多数场景）；Dialog 需点遮罩 |
| 滚动文档 | 跟随锚点的 Popover 重新定位；**命令条通常直接关闭** |
| 编辑器失焦 | 命令条关闭；**评论面板保留** |
| 同层互斥 | 气泡条与块手柄菜单不会同时出现 |

## 8. Markdown 输入规则表【实机】

| 语法 | 触发 | 语法 | 触发 |
| --- | --- | --- | --- |
| 一级标题 | `# ` + 空格 | 增加缩进 | `Tab` |
| 二级标题 | `## ` + 空格 | 减少缩进 | `Shift + Tab` |
| 三级标题 | `### ` + 空格 | 引用 | `> ` + 空格 |
| 有序列表 | `1. ` + 空格 | 行内代码 | `` `代码` `` **+ 空格**（✅ 实测 2026-10-24 batch113） |
| 无序列表 | `- ` 或 `* ` + 空格 | 代码块 | ` ``` ` 或 ` ```lang ` |

## 10. 边界与错误态

| 场景 | 期望行为 |
| --- | --- |
| 文档最后一个块被删 | **保底保留一个空段落** |

## 12. 修订模式（Suggest Mode）完整规格【实测 · batch157/158/159/160】

> **一句话**：修订模式产出的是**「建议」对象**，不是正文 —— 改动以 `<span class="revision-container">` 包裹的**行内标记**呈现，配一个**右侧建议面板**（与评论面板同一套壳 `comment-panel__fjFpT`），面板头部**独有**「接受 / 拒绝」两个彩色图标按钮。**接受 = 标记消失变成正文，拒绝 = 标记连同改动一起消失**。

### 12.2 修订标记的 DOM 与配色

修订模式下**每一次键入都立即落标记**，两种标记结构不同：

```html
<!-- 新增（insert）：蓝字 + 2px 蓝下划线 -->
<span class="revision-container" data-inline-wrapper="true"
      style="--revision-border-color: var(--B700); color: var(--B700);">
  <span class="text-revision revision-id-<rid> author-<uid>" data-string="true" data-leaf="true">新增文本</span>
</span>

<!-- 删除（delete）：原色字 + 删除线 + 10% 蓝底 -->
<span class="revision-container" data-inline-wrapper="true"
      style="--revision-border-color: var(--B700); background-color: rgba(var(--B700-raw), 0.1);">
  <span class="revision-linethrough text-revision revision-id-<rid> author-<uid>" data-string="true" data-leaf="true"
        style="--revision-border-bottom-color:var(--text-title);--revision-linethrough-color:var(--B700);">C</span>
</span>
```

| 项 | 新增 ins | 删除 del |
| --- | --- | --- |
| 外层 | `span.revision-container[data-inline-wrapper]` | 同左 |
| 内层 | `span.text-revision.revision-id-*.author-*` | `span.revision-linethrough.text-revision.revision-id-*.author-*` |
| 文字色 | **`#0442D2`**（= `rgb(4,66,210)`） | **`#1F2329`**（保持原色，**不变灰**） |
| 底色 | 透明（hover/聚焦 **`rgba(4,66,210,0.1)`**） | **`rgba(4,66,210,0.1)`** 常驻 |
| 装饰线 | `border-bottom: 2px solid #0442D2`（容器上） | `text-decoration: line-through`（内层），线色 `#0442D2`、粗 2px |
| 圆角 / 内边距 | `0` / `0` | 同左 |
| 尺寸 | 容器高 **27**（16px 正文行 + 2px 下划线外扩），内层文字行高 **19** | 同左 |
| 行为标记 | 无 | 无（**不区分作者颜色**，全部同色） |

> 🔴 **复刻坑（重要）**：飞书用 CSS 变量 `--B700` / `--B700-raw` 下发修订色，而这两个变量**挂在某个中间层、作用域不稳** —— 实测同一元素两轮采集 `background-color` 在 `rgba(4,66,210,0.1)` 与 `rgba(0,0,0,0)` 之间跳（`--B700-raw` 取不到时 `rgba(var(--B700-raw),0.1)` 属 invalid at computed-value time，整条声明失效）。**复刻时直接写死 `#0442D2`，不要引入 `--B700` 这类可缺省的中间变量。**

### 12.5 CRUD 闭环

| 操作 | 路径 | 结果 |
| --- | --- | --- |
| **增** | 修订模式下直接键入 → 立刻形成 `revision-container` 蓝字；按 `Delete` 形成 `revision-linethrough` 删除标记 | 无需任何「开始建议」按钮 |
| **接受** | 面板头 `accept-btn`（绿勾 16×16） | 标记连同 `<span>` 一起消失，文本转为正常正文；**无二次确认、无 toast** |
| **拒绝** | 面板头 `reject-btn`（红叉 16×16） | 标记 + 改动**一起消失**（删掉的文字**不回来**）。实测：`revision-container` 2 → 1、`revision-linethrough` 1（另一条）、`revision-panel` 2 → 1，**无二次确认、无 toast** |
| **查（跳转）** | `go-next-btn` / `go-previous-btn` 在同文档的多条修订间前后跳；首条时 `prev` 置灰 + `disabled` | 面板跟着滚动 |
| **查（定位）** | 点正文里的修订标记 → 对应面板展开到 169 高并高亮 | — |
| **复制锚点** | `copyAnchor-btn` → 「复制链接」 | 与评论面板同 |
| **改** | ❌ 修订本身**不可编辑**；要改只能拒绝后重做 | 面板里没有「编辑」入口 |
| **删** | = **拒绝**（没有独立删除键） | — |

> **判定口径**：`reject` 语义是「**整条建议作废**」，会**丢弃改动本身**（删除的原文不会恢复、新增的文字会被移除）；`accept` 是「**采纳建议**」。二者均**不可撤销**（文档级 Undo 可回退，但面板层无确认）。
