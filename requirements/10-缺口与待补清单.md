## 6.2 采集方法学坑（Playwright 探针的「假数据」来源）

> 本节不是需求，是**避免把采集 bug 当飞书行为写进需求**。表格专项踩了 3 次，全部因此。

### 坑 1 · 表格虚拟化 → 离屏表会被「降级」

| 现象 | 真因（batch196 定位） |
| --- | --- |
| 取 `last` 拿到 `nCol:0 / nTr:1 / cols:[]` | 该块**在视口外，内部 `table` 被虚拟化剥掉了 `colgroup` 和行**。块本身还在，只是内容被 stub |
| 点「标题列」后表少 1 行（`nRow:1 / nCol:0`） | 同上 —— 读到的是离屏 stub。**飞书没有删行**，batch191 的判读是错的 |
| `nTable` 数量会变（2 张 / 3 张） | 滚动过程中挂载状态在变；**数量不稳定，但 `nCol>0` 的那张一定是活表** |

**口径（写脚本必须照此）**：

```js
const good   = cand.filter(c => c.nCol > 0);                        // ① 必须有 colgroup
const inView = good.filter(c => c.top >= 100 && c.bottom <= 820);    // ② 必须在视口内
const main   = inView.length ? inView[inView.length - 1]            // ③ 取视口内最后一张
             : (good.length ? good[good.length - 1] : cand[cand.length - 1]);
```

> 🔴 **不要**用 `cand[cand.length-1]` 直接取末张（batch192 因此选到 `y=-414` 的离屏表，后续全空）。
> 🔴 **不要**只按 `top/bottom` 过滤（batch193 因此选到 `nCol:0` 的 stub）。
> 🔴 **硬前置**：所有取坐标的操作前，必须 `ensureVisible()` 循环滚动直到 `vis === true`；batch195 就是少了这一步，A4/A5/A6 三段全部空转（坐标 `y=-178`）。
> 🔴 一张表都没挂载时（`list.length === 0`），要**向下滚 620px 逼挂载**，不能直接 `return null`（batch196 第一版就这样，`B0 初始全表 = []`）。

### 坑 2 · 文档滚动容器不是 `window`

```js
document.querySelector('.bear-web-x-container').scrollTop = ...   // ✅
window.scrollTo(0, y)                                             // ❌ 无效
```

配套 `centerTable()`：循环最多 12 次，按 `bbox.top - 300` 步进，直到 `top >= 140 && bottom <= 780`。

### 坑 3 · 单元格选区不能用 `mouse.down/move/up`

表格单元格有独立 pointer 处理，`move` 过程**不更新选区**。唯一可行：

```js
await mouse.click(A); keyboard.down('Shift'); await mouse.click(C); keyboard.up('Shift');
```

### 坑 4 · 浮条不是固定一种形态

| 形态 | 宽度 | `data-name` 齐不齐 |
| --- | --- | --- |
| 单格（右键式） | **644** | 缺 `MergeCell` / `remove` |
| 多格选区 | **685** | 齐 |

### 坑 6 · `Backspace` 次数必须按「目标块剩余字符数」精确计算

**症状**：batch614 想清空 3 个探针（各写 4 个字符 `PRB1/2/3`），按「每块 8 次 Backspace 求稳」的固定次数连按，结果**第 1 次就清空了当前块，后面 7 次继续往前吞** —— `bid:464`（bitable「待办管理」）与紧随其后的 text 块被整块删除，`topN 9 → 7`。

**根因**：文档里 Backspace 在**块首**会**合并到上一块**（不是只删字符）。

**正确做法**：
- 清字符用 `Meta+A`（**选区在块内**时）→ 一次 `Backspace`；批量删块用 `Meta+ArrowLeft`（行首）→ `Backspace`（块首合并）；
- 每按一次都回读 `topN` 与目标块 `innerText`，**看到块数变化就停**；
- 兜底：飞书版本历史可整篇还原（batch618 已跑通），但那只是**逃命通道**，不是可依赖的流程。

### 坑 7 · 子面板/弹窗里的按钮，必须按「精确文字 + 合理尺寸」在 DOM 里挑

**症状**：两轮栽在同一件事上——
- batch610 按坐标点「减少缩进」，落在与 `AlignList` 子面板**矩形重叠**的 `BlockColor` 色板上（色板 `230×202 @(278,308)`、子面板 `230×185 @(279,285)`）；
- batch617 点「还原」，`document.querySelectorAll('[class*="btn"]')` 先命中的是 **372×44 的按钮行容器**（`innerText: "还原 取消"`），点它中心**什么也不会发生**，还原静默失败。

**正确做法**：
- 先 `evaluate` 在 DOM 里按 `data-name` / `innerText === '精确文案'` **定位到唯一元素**，并断言 `20 <= width <= 140`（排除容器）、`height >= 14`；
- 再拿它的 `cx/cy` 派发完整指针序列（`move` → `down` → `up`）；
- **点完必须回读结果**（`topN` / 面板是否关 / 弹窗是否消失），不能「点了就算成」。
