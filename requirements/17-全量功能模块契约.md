# 17 · 全量功能模块契约（官方 API × 网页实机 × 本地实现对账）

> 本文件是开发对账的**唯一入口**：把源需求中的每个功能模块归一为 `moduleId`，并为每个模块给出增删改查、接口、字段、权限、失败语义和本地落点。视觉细节仍以 `02/03/04/06/11/16` 为真源，数据模型以 `01` 为真源，端到端验收以 `15` 为真源。
>
> **来源优先级**：
> 1. `[官方API]`：源文档第 20 章（开放平台 docx API、BlockType、BlockData、限制与错误码）；
> 2. `[实机]`：源文档第 21 章（目标租户网页 DOM、菜单、浮层、网络路径）；
> 3. `[本地契约]`：`01`~`16` 已落地的 lark-doc Provider / Tiptap 语义；
> 4. `[推断]`：官方或实机没有给出的失败分支，只能作为我方接口约束，不得冒充飞书报文。
>
> **CRUD 约定**：`C=create` 增、`R=read` 查、`U=update` 改、`D=delete` 删。`—` 表示该模块不拥有此操作；`block-delete` 表示由通用块删除接口完成；`unsupported` 必须返回 `ERR_UNSUPPORTED_OPERATION`，不能静默吞掉。

## 17.1 统一模块记录和操作类型

### 17.1.1 `FeatureModule` 注册表

```ts
type ModuleKind =
  | 'document' | 'block' | 'inline' | 'command' | 'overlay'
  | 'workspace' | 'permission' | 'collaboration' | 'embed' | 'export';
type Tier = 'P0' | 'P1' | 'P2' | 'P3' | 'V2' | 'C' | 'Later';
type CrudMode = 'native' | 'block-delete' | 'provider' | 'unsupported' | 'host';

interface FeatureModule {
  moduleId: string;                 // 稳定 ID，例如 block.text / overlay.jira.issue
  kind: ModuleKind;
  tier: Tier;
  sourceRefs: string[];             // 源文档 20/21 章或 15/16 章编号
  localRefs: string[];              // requirements 文档落点
  observedNames: string[];           // 中文命令、data-name、data-block-type、DOM 类名
  blockType?: string;               // 官方 BlockType 或实机 data-block-type
  crud: {
    create: CrudMode;
    read: CrudMode;
    update: CrudMode;
    delete: CrudMode;
  };
  fields: string;                   // 字段配置档 ID，见 17.4
  api: string;                      // API 契约 ID，见 17.3
  gapGrade?: 'A' | 'B' | 'C' | 'D' | 'E' | null;
  capability?: string[];            // 01/05 的能力位
  fallback: 'none' | 'readonly' | 'preserve' | 'disabled' | 'host-owned';
  acceptance: string[];             // 可执行断言 ID
}
```

每一条模块记录必须同时有 `crud`、`fields`、`api`、`fallback`，否则只能算导航条目，不能算开发级需求。

### 17.1.3 所有模块共用的主键

| 字段 | 类型 | 来源/用途 |
| --- | --- | --- |
| `documentId` | `string` | 文档主键；知识库页面 token 在网页端也作为 doc token 使用 |
| `blockId` | `string` | 官方 Block ID；根 Page Block 的值等于 `documentId` |
| `recordId` | `string` | 网页 DOM `data-record-id`，协同 `change_map` 必须用它，不能用短 `data-block-id` |
| `blockType` | `string/int` | 官方枚举值或网页 `data-block-type` |
| `parentId` | `string` | 父块 ID；根块无父节点 |
| `children` | `string[]` | 子块 ID 有序列表 |
| `revisionId` | `number` | 官方 OpenAPI 文档版本；本地 Provider 可映射为 `rev` |
| `attrs` | `Record<string, unknown>` | 本地渲染属性；未知字段必须透传 |
| `createdAt/updatedAt` | `number` | ms epoch |
| `deletedAt` | `number|null` | 文档级软删除状态 |

## 17.2 官方 docx 文档/块 API（字段级）

### 17.2.1 文档级路由

| 操作 | HTTP + 路径 | 请求字段 | 响应核心字段 | 限制/错误 |
| --- | --- | --- | --- | --- |
| 创建文档 | `POST /open-apis/docx/v1/documents` | `folder_token?`, `title?`（1~800 字符） | `document_id`, `revision_id`, `title` | `1770001`, `1770002`, `1770020` |
| 读取元数据 | `GET /open-apis/docx/v1/documents/:document_id` | `document_id`, `document_revision_id?` | `document_id`, `revision_id`, `title`, `display_setting`, `cover` | 无权返回 403/400 |
| 读取纯文本 | `GET .../:document_id/raw_content` | `lang?`（0/1） | `content` | 特殊频控 |
| 读取全部块 | `GET .../:document_id/blocks` | `page_size?`, `page_token?`, `document_revision_id?` | `items[]`, `page_token`, `has_more` | 按先序返回，索引 0 必须为 Page |
| Markdown/HTML 转换 | `POST /open-apis/docx/v1/documents/blocks/convert` | `content_type`, `content`, `user_id_type?` | `blocks[]` | `content` 1~10485760 字符；单次最多 1000 块 |

文档元数据：

```ts
interface FeishuDocumentData {
  document_id: string;
  revision_id: number;
  title: string;
  display_setting?: {
    show_authors?: boolean;
    show_comment_count?: boolean;
    show_create_time?: boolean;
    show_like_count?: boolean;
    show_pv?: boolean;
    show_uv?: boolean;
  };
  cover?: { token: string; offset_ratio_x: number; offset_ratio_y: number };
}
```

本地 `DocumentAPI` 的 `create/rename/duplicate/remove/restore/listDeleted/purge` 见 `05 §5.13`；它是本地文档集合适配层，不冒充飞书 OpenAPI 中不存在的“删除文档”路由。

### 17.2.2 块级路由和请求字段

| 操作 | HTTP + 路径 | 请求字段 | 返回 |
| --- | --- | --- | --- |
| 读取单块 | `GET .../:document_id/blocks/:block_id` | `document_revision_id?` | `Block` |
| 读取子块 | `GET .../:document_id/blocks/:block_id/children` | `page_size?`, `page_token?`, `document_revision_id?`, `with_descendants?` | `items[]`, `page_token`, `has_more` |
| 创建子块 | `POST .../:document_id/blocks/:block_id/children` | `children[]`, `index?`, `document_revision_id?` | 新建块 ID、revision |
| 创建嵌套块 | `POST .../:document_id/blocks/:block_id/descendant` | `children_id?`, `index?`, `descendants[]`, `document_revision_id?` | 新建块树、revision |
| 更新单块 | `PATCH .../:document_id/blocks/:block_id` | `update_*` 子请求、`document_revision_id?` | 更新后的块、revision |
| 批量更新 | `PATCH .../:document_id/blocks/batch_update` | `requests[]`, `document_revision_id?` | 每个子请求结果、revision |
| 删除子块 | `DELETE .../:document_id/blocks/:block_id/children/batch_delete` | `start_index`, `end_index`, `document_revision_id?` | revision |

### 17.2.3 官方限制和统一错误码

| 错误码 | 含义 | 本地统一码 |
| --- | --- | --- |
| `1770001` | 参数非法 | `INVALID_ARGUMENT` |
| `1770002` | 文档/块不存在 | `NOT_FOUND` |
| `1770003` | 资源已删除 | `RESOURCE_DELETED` |
| `1770004` | 文档块数超限 | `QUOTA_BLOCKS` |
| `1770005` | 嵌套层级过深 | `QUOTA_DEPTH` |
| `1770006` | schema 不匹配 | `SCHEMA_MISMATCH` |
| `1770007` | 单块 children 超限 | `QUOTA_CHILDREN` |
| `1770008` | 文件过大 | `QUOTA_FILE` |
| `1770010`/`1770011` | 表格列/单元格超限 | `QUOTA_TABLE` |
| `1770012` | 分栏列超限 | `QUOTA_GRID_COLUMNS` |
| `1770013`/`1770014` | 资源关联/父子关系错误 | `RELATION_MISMATCH` |
| `1770019` | Block ID 重复 | `DUPLICATE_BLOCK_ID` |
| `1770020` | 文档正在创建副本 | `COPY_IN_PROGRESS` |
| `1770021` | revision 差值超过 1000 | `REVISION_TOO_OLD` |
| `99991400` / HTTP 429 | 限频 | `RATE_LIMITED` |

| `grid` | `column_size(2..5)`, `children[]` | `layout`, `gap` | `grid_column` 只能由 grid 操作创建 |

| `image` | `token` 或 `source` | `width`, `height`, `crop`, `alt`, `align` | 创建块→上传素材→`replace_image` |
| `file` | `file_token` | `name`, `size`, `mime_type`, `view_type`, `url` | 视图块由服务端自动生成；视频沿用 file 壳 |
| `file_view` | `block_id`, `view_type` | `pip`, `width`, `height`, `status` | 官方支持文本/卡片/预览三视图；画中画只在网页版视频预览开启 |
| `iframe` | `url` | `title`, `height`, `bridgeVersion`, `sandbox` | 官方允许 Create/Read，Update 仅由 iframe 内部桥完成 |

## 17.7 模块状态、权限和失败语义

### 17.7.1 能力位映射

| 能力位 | 影响模块 | false 时要求 |
| --- | --- | --- |
| `canView` | 所有 document/block/overlay | 整页只读遮罩或 404；不创建编辑器实例 |
| `canEdit` | block/command/embed/table | 入口置灰；Provider 写方法再次拒绝；不做乐观更新 |
| `canComment` | comment/toolbar/block-handle | 评论入口置灰，已有评论仍可读 |
| `canResolveComment` | comment | resolve/reopen 置灰 |
| `canCreateVersion` | history/version | 创建版本置灰 |
| `canRestoreVersion` | history/version | 恢复置灰 |
| `canExport` | export/topbar | Word/PDF/Markdown 三项置灰，不发请求 |
| `canManagePermission` | share/permission | 降级为“分享只读链接”，不弹管理面板 |

### 17.7.2 状态枚举

所有块/嵌入至少支持：`idle | loading | ready | empty | error | readonly | deleted`；

- `loading` 不得把 `blockId/recordId` 丢掉；
- `error` 必须保留原始 `attrs`，允许重试或删除；
- `readonly` 仍可 Read，不能把外部内容伪装成已保存；
- `deleted` 只由文档/回收站 API 产生，不能用块删除冒充文档删除。

### 17.7.3 不支持操作的统一响应

```json
{
  "ok": false,
  "error": {
    "code": "ERR_UNSUPPORTED_OPERATION",
    "message": "该模块不支持当前操作",
    "detail": {"moduleId": "block.diagram", "operation": "create"},
    "retryable": false,
    "source": "local"
  }
}
```

### 17.7.4 未知块/第三方块保真

对 `block.undefined`、`block.ai_template`、未注册的 `isv`/`iframe`：

1. 读取时保留 `blockType`、`recordId`、完整 `attrs`、原始 `ssrData`；
2. 编辑器不认识内容时只渲染 `readonly/preserve` 壳，不猜测成普通文本；
3. 删除只允许用户显式调用 `BlockModuleAPI.remove`；
4. 保存/导出必须透传未知字段；
5. `isFallback` 只用于埋点，不产生“未知块占位卡”视觉。

### 17.11.3 实现约束与官方对账

1. `ReactionAPI` 的表情回复只通知评论创建者；图文回复通知所有参与者，评论私有性和通知收件人必须在服务端按可见集合计算。REA 只证明了 add/delete 路径，不证明请求 body 的全部字段，因此 `objToken/objType/reactionType` 是适配器最小稳定字段，实际报文需要 E2 回放确认。
2. `DocumentSubscriptionAPI` 的 comment 订阅只在桌面端/网页版提供入口，移动端不显示开关；订阅状态仍应可由统一服务端查询，避免跨端打开时状态丢失。
3. `SurveyProvider` 与现有 `InfoCollectionAPI(kind:'info_collection')`、`poll` 块完全分离。REA 的 `/api/survey/pull/` 只能证明存在独立 provider；题目配置和结果权限必须继续标为 ◐，不能把“卡片显示参与人数”当作问卷结果已闭环。
4. `RceTransport` 只承载客户端变量、presence、游标、心跳和变更通知。正文保存/冲突重试必须继续使用 `CollaborationModuleAPI.submitChanges` 对应的 `POST /space/api/docx/blocks/user_change`；长 `data-record-id`、`X-CSRFToken` 和业务 `code` 解析均属于必测条件。
5. 官方操作手册（本地 `飞书官方文档功能原文汇编.md`）确认导入支持多格式与批量导入、副本不带评论/历史/分享/权限、版本移动端只读、移动端无复制权限时同时禁止截屏/录屏、操作记录覆盖分享授权/创建副本/下载/权限变更。REA 静态路径只能补接口面，不能提升这些未做异常回放的 E 等级。
