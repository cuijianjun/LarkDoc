# 03 · 工具栏与菜单（命令条 / 气泡条 / 斜杠菜单 / 块菜单）

> 本文件覆盖飞书文档**所有命令入口**的像素级规格与 CRUD 闭环。
> 数值标注：【实测】= Playwright 实机 `getComputedStyle` + `getBoundingClientRect` 读取；【推导】= 由实测值算得；【待补】= 未拿到。
>
> **核心架构结论（复刻必读）**：飞书所有命令条**共用一套组件**（`.panel-menu-item` / `.panel-submenu-item` / `.menu-divider-item`），差异只在 `data-name` 与容器尺寸。工程上应实现**一个 `LarkMenu` 组件 + 一份命令注册表**，而不是每种菜单各写一份。

### 通用状态色【实测】

| 状态 | 背景 | 说明 |
| --- | --- | --- |
| normal | `rgba(0,0,0,0)` | 透明 |

| active / expanded | `rgba(31,35,41,0.1)` | 子菜单展开时父项保持该底色（实测 `text turninto submenu` 展开后仍 0.1） |

> **hover 采样陷阱**：`highlight submenu` 曾读到 `rgba(31,35,41,0.05)`——这是**过渡动画中间帧**。稳定态恒为 `0.1`。复刻时 hover 背景必须用 `0.1`，不要用 `0.05`。

### 子菜单行为差异【实测】

| 项 | 类名附加 | 展开方式 |
| --- | --- | --- |
| `text turninto submenu` / `text align` / `more` | `no-click-action` | **点击**才展开（点了不执行命令） |
| `highlight submenu` | `hot-area-unique` | **hover 即展开**（无需点击） |

### 图标色 Token【实测】

类名规律 `color-{b,g,i,o,t,y,w}-500` + 少量特例。复刻应直接把这一串做成图标色板：

`color-b-500`（蓝）/ `color-g-500`（绿）/ `color-i-500`（靛）/ `color-o-500`（橙）/ `color-t-500`（青）/ `color-y-500`（黄）/ `color-w-500`（紫）；特例：`color-b-600`、`colorful-indigo`、`color-bitable-brand`、`meego-sub-item-icon`、`diagram-url`。

## 3.1 文本浮动工具栏（选区气泡条）

### ① 功能定义
选中**非空文本**时在选区上方浮出的横向命令条，执行行内格式（加粗/斜体/…）与文本级块转换。

### ② CRUD 闭环
| 操作 | 触发 | 结果 |
| --- | --- | --- |
| **创建（显示）** | 鼠标拖选 / `Shift+方向键` 选中 ≥1 字符 | 气泡条出现在选区上方 |
| **读取** | 每个按钮按下沉态反映当前选区格式（加粗已生效则高亮） | 【待补】active 选中态色 |
| **更新** | 点按钮 → 命令立即作用于选区，气泡条**保持不关闭**（可连续操作） | — |
| **删除（隐藏）** | `Escape` / 点击别处 / 选区清空 / 滚动使选区离屏 | 卸载 |

### ③ 显示 / 隐藏规则
- **显示条件**：选区非空 且 编辑器 focused。
- **隐藏条件**：选区为空 → 不显示；选区跨块时**仍显示**（飞书允许跨块选区）。
- **避让**：气泡条默认在选区**上方**；上方空间不足（被吸顶栏遮挡）时**翻到选区下方**。
  - 吸顶偏移量算法：`bubbleSafeTop()` = `.lark-doc-topbar` / `.lark-doc-toolbar` 中 `position: sticky|fixed` 且 `top ≤ 1` 的元素底边 + 6px。菜单 `top` 的 clamp 下界用它。

### ④ UI 像素规格【实测】

容器：`overlay-container` → `position: fixed`，**z-index: 87**，`594×42`（含 AI 项时）。

#### ④-2 绝对坐标复核【实测 · batch64 · 真实双击选词后全量枚举 `[data-name]`】

> ⚠️ **顺序陷阱**：飞书是 **加粗 → 删除线 → 斜体 → 下划线**（`Bold / Strikethrough / Italic / Underline`），**删除线在斜体之前**。常见的 `B I U S` 直觉顺序是错的，照抄会错位。

### ⑤ 状态交互
- hover：`rgba(31,35,41,0.1)`，圆角 4px。
- 点击图标项：立即执行，**气泡条不关闭**。
- 点击 submenu：展开二级面板，**一级保持展开底色 0.1**。
- `comment`：受 `canComment` 能力控制（false 时静默禁用）。

### ⑥ 字段接口
```ts
interface TextCommandBarProps {
  variant: 'selection' | 'contextmenu'   // contextmenu 追加 text toolbar link
  commands: string[]                     // data-name 序列
  capabilities: { canComment: boolean }
  safeTop: number                        // 吸顶避让下界
}
```

## 3.3 块手柄菜单（六点 drag-handle）

### ① 功能定义
hover 任意块 → 块左侧浮出「类型图标 + 六点拖拽手柄」→ 点图标展开块级命令菜单。

### ② CRUD 闭环
| 操作 | 触发 | 结果 |
| --- | --- | --- |
| 显示手柄 | 鼠标进入块区域 | 手柄出现在块左侧外部 |
| 拖拽 | 按住六点手柄拖动 | 整块移动（含缩进子树） |
| 展开菜单 | 点击类型图标 | 纵向菜单展开 |
| 执行命令 | 点菜单项 | 剪切/复制/删除/转换/… |
| 隐藏 | 鼠标移出块区域（**160ms 延时**，跨 6px 间隙不闪） | 卸载 |

### ③ 显示 / 隐藏规则
- 手柄在块**左侧外部**（块 x − 手柄宽），不占正文宽度。
- 鼠标移开 **160ms 延时关闭**——这是为了允许鼠标从块穿越 6px 间隙移到手柄/菜单上而不闪断。
- 无权限时菜单项**静默禁用**（不置灰）。

### ④ UI 像素规格【实测】

## 3.4 斜杠菜单（`/` 快速插入）

### ① 功能定义
行首或空格后输入 `/` 弹出插入菜单，支持拼音/英文关键字过滤。

### ② CRUD 闭环
| 操作 | 触发 | 结果 |
| --- | --- | --- |
| 打开 | 输入 `/` | 菜单在光标处弹出 |
| 过滤 | 继续输入文字 | 按**标题关键词 + 分类名**双重匹配（实测输入「视频」同时命中「视频或文件 / 内嵌网页 / 哔哩哔哩 / 优酷视频」） |

品牌色 **`#1456F0`**（`rgb(20,86,240)`）。

### 【实测结论】wiki 容器下顶栏不渲染

在本次实测文档（`docx-in-wiki` 容器，即知识库 wiki 页）下，**`bear-web-toolbar` 确认不渲染**：

| 实测项 | 结果 |
| --- | --- |
| `document.querySelectorAll('.bear-web-toolbar').length` | **0**（wiki 页面状态下该容器不存在） |
| 该状态下正文区唯一可见的内嵌工具条 | `.code-block-header-toolbar`（**264×22**，代码块 hover 时出现，见 [02 §7](./02-块类型规格总表.md)） |
| 顶部 64px 区域实际承载 | 文档标题面包屑 + 右侧图标按钮组（24×24 / radius 6 / 命中色 `rgba(31,35,41,0.04)`） |

> **结论**：飞书 wiki 页与普通 docx 页是**两套外壳**。wiki 页左侧 300px 是空间目录树（`.wiki-sidebar-wrap` z90），顶部没有编辑工具条；**编辑工具条只存在于普通 docx 页**。复刻时按「两种容器模式」实现：
> - `mode: 'wiki'` —— 侧边栏 300px + 顶栏 64px（无编辑工具条）
> - `mode: 'docx'` —— 无侧边栏 + 顶栏 64px + **`bear-web-toolbar` 编辑工具条**

**`bear-web-toolbar` 预期规格（按飞书设计体系推导，待换普通 docx 页复采）**：

| 项 | 预期值 | 依据 |
| --- | --- | --- |
| 高度 | **40px** | 与块工具条 `.docx-menu-wrapper`（42px）同族 |
| 按钮尺寸 | **24×24** radius 4 | 与块工具条内菜单项一致（[04 §7](./04-浮层与弹窗.md)） |
| hover 背景 | `rgba(31,35,41,0.1)` | 控件类 hover 统一值（[06 §7.2](./06-视觉规格Token.md)） |
| 选中前景 | `#336DF4` | 与 `text align` 子菜单选中态一致（§3.2.2 实测） |
| 分隔线 | 1px `#DEE0E3`，高 16，左右 margin 4 | 飞书菜单通用分隔线 |
| 图标 | 18×18（内层 16×16）svg | 与 `text align` 子菜单图标同规格 |

> 该容器未采到前，**不要凭空编造按钮清单**；实现时先按 `mode: 'wiki'` 落地，docx 模式留接口位。

## 3.7 复刻落地建议（工程）

1. **一个 `LarkMenu` 组件**承载全部菜单；`data-name` 作为唯一命令 id，与快捷键、右键、气泡条**共用同一份命令注册表**。
2. 命令条三变体：`selection`（气泡条）/ `contextmenu`（右键，追加 link）/ `block`（块手柄，纵向 214×32）。
3. hover 底色统一 `rgba(31,35,41,0.1)`；圆角 4（项）/ 6（容器）；阴影 `rgba(31,35,41,0.1) 0 4px 8px 0`。
4. 所有浮层**无滚动条**（外层容器不出现 scrollbar），超长项内部滚动。
5. 吸顶避让：`bubbleSafeTop()` = sticky/fixed 且 `top ≤ 1` 的栏底边 + 6px。
