## 通用规范（读文档前必看）

### 1. 每个功能模块的固定结构

本规格文档对每个功能模块统一按 **6 段式**描述，确保闭环：

```
① 功能定义     —— 这个模块是什么、解决什么问题
② CRUD 闭环    —— 增/删/改/查 各自入口、操作路径、边界条件
③ 显示与隐藏   —— 何时出现、何时消失、触发条件、互斥关系
④ UI 像素规格  —— 尺寸/间距/字号/行高/颜色/圆角/阴影（精确到 px 与 rgb）
⑤ 状态与交互   —— hover / active / focus / disabled / 选中态 的视觉差异
⑥ 字段与接口   —— 数据结构字段含义、相关 API
```

### 2. 数值标注约定

- 【实测】浏览器真实读取，可直接照抄
- 【推导】换算/外推，实现后需回归验证
- 【待补】尚未采集到，勿凭空编造

### 3. 颜色书写

飞书实测色值以 `rgb(r, g, b)` 为准，本文档同时给出 HEX 便于使用：

| 用途 | rgb | HEX |
| --- | --- | --- |
| 正文主色 | `rgb(31, 35, 41)` | `#1F2329` |
| 表格/边框线 | `rgb(222, 224, 227)` | `#DEE0E3` |
| 纯白 | `rgb(255, 255, 255)` | `#FFFFFF` |

> 完整颜色 Token 见 [06-视觉规格Token.md](./06-视觉规格Token.md)

### 4. 与设计文档的关系

- `DEVELOPMENT.md`：记录**本项目代码怎么写**、踩坑、发布流程 → 开发过程文档
- **本目录**：记录**要复刻成什么样**（飞书的规格） → 需求规格
- 二者冲突时：**以本目录的飞书实测值为准**（因为目标是 1:1 复刻飞书）

### 🚫 已确认「不存在」（别再找）

| 项 | 结论 |
| --- | --- |
| 折叠块（toggle） | 飞书网页版 slash 一级菜单 **21 项**中无此项。折叠只作为标题/列表的**能力**存在，不是块类型。 |
| 块 `focused` 的视觉高亮 | **不存在**。`.focused` 类不承载任何样式，仅有 2 个元素带该类（块本身 + `.zone-container…text-editor-focused`）。 |
| 目录项 `active` 的视觉高亮 | **不存在**。color/bg/伪元素/border 四项全同，`active` 仅供滚动跟随。 |
| 空块占位文案 | 飞书空块**不显示任何占位提示**（伪元素 content 为空串、无 `data-placeholder`）。`#BBBFC4` 只是占位色 Token，供宿主自定义时使用。 |
| 表格单元格底色 | **不存在**（恒透明）。原记 `#F2F3F5` 是 hover/选中态误读，已作废。 |
| 深浅色板「同一色改透明度」关系 | **不存在**。深色 32 色与浅色是各自独立的一套，不能用 `filter: brightness()` 推导。 |
| 查找替换「区分大小写 / 全字匹配 / 正则」 | **不存在**（飞书网页版没有这三项）。`More` 是 **Tabs 溢出指示器**，点开是全局帮助菜单，不是选项面板。 |
| 输入 URL + 空格自动生成链接 | **不存在**。飞书不做 URL 自动识别，必须走 `Cmd+K`（或气泡条 `text toolbar link`）。 |
